# 用单调性夹逼相邻积分比值

跨两项递推不能直接给相邻比值，但正性和单调性可把中间项夹在两项之间。先保证分母正，再除法，并确认所求比值方向。

**自编例题。** 沿用 $I_n=\int_0^{\pi/2}\sin^nx\,dx>0$。因 $0\le\sin x\le1$，有 $I_{n+2}\le I_{n+1}\le I_n$。再由[分部递推](parts-recurrence.md)，

$$
\frac{n+1}{n+2}=\frac{I_{n+2}}{I_n}
\le\frac{I_{n+1}}{I_n}\le1.
$$

两界趋一，所以 $I_{n+1}/I_n\to1$。若求倒数，则夹界为 $1\le I_n/I_{n+1}\le(n+2)/(n+1)$，结论仍为一。

不能从两项都趋零直接得到比值为一。[2019-18](../questions/2019-301-18.md)支持这种思路及 $n+2$ 纠错记录，未保存原积分，所以此处不宣称复算了其递推。
