# 用幂代换消去根式

多个分数幂出现时，找分母的公倍数作幂代换；先写实值定义域与新变量分支，同时替换微分和积分限。根式消失后通常成为有理积分。

**自编例题。** 计算 $I=\int_0^1 dx/(1+\sqrt x)$。令 $t=\sqrt x\in[0,1]$，则 $x=t^2,dx=2t\,dt$，于是

$$
I=\int_0^1\frac{2t}{1+t}\,dt
=\int_0^1\left(2-\frac2{1+t}\right)dt=2-2\ln2.
$$

零点处逆映射导数无界不妨碍这里使用光滑的 $x=t^2$ 正向换元。若有 $\sqrt{x^2}$，必须先写成 $|x|$，不能默认等于 $x$。[2018-15](../questions/2018-301-15.md)的原式及积分限未全，不能靠“根式换元”恢复原题类型。
