# 循环分部后解积分方程

指数与正弦、余弦的乘积再次分部常会回到原积分。给原积分命名，两次分部后把它移到同一侧，核对移项系数非零，再整理常数。

**自编例题。** 记 $I=\int e^x\sin x\,dx$。先把 $e^x$ 积分，得 $I=e^x\sin x-J$，其中 $J=\int e^x\cos x\,dx$。同样分部得 $J=e^x\cos x+I$，因此

$$
2I=e^x(\sin x-\cos x),\qquad
I=\frac{e^x}{2}(\sin x-\cos x)+C.
$$

中间等式理解为选定原函数后吸收常数，最终必须补 $C$。回求导得到 $e^x\sin x$。若得到的是 $I=I$，只是恒等式，没有形成可解方程，需要另换分部方向。
