# 识别内函数并凑微分

观察一部分表达式的导数是否已经作为乘子出现。选定内函数 $u$ 后实际写出 $du$，补偿常数因子，再用基本原函数；最后求导回查，尤其检查对数定义域。

**自编例题。** 在实轴求

$$
\int\frac{x}{1+x^2}\,dx.
$$

取 $u=1+x^2>0$，$du=2x\,dx$，故积分为 $\frac12\ln(1+x^2)+C$。回查导数为 $x/(1+x^2)$，补偿系数正确。

再如 $\int e^{\sin x}\cos x\,dx=e^{\sin x}+C$。这里仅用复合求导，不要求 $\sin x$ 在全实轴单调；若要反解换元分支，则必须另外限定区间。没有内函数导数时，不能仅把某部分命名为 $u$ 就删除剩余因子。
