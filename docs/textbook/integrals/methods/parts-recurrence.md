# 通过分部建立积分递推

先写清指标范围，挑一因子求导使幂次降低，再将剩余三角平方或代数项改写为原积分及低阶积分。移项后列出足够初值，检查边界乘积。

**自编例题。** $I_n=\int_0^{\pi/2}\sin^nx\,dx$，对整数 $n\ge2$ 取 $u=\sin^{n-1}x,dv=\sin xdx$。端点乘积为零，所以

$$
I_n=(n-1)\int_0^{\pi/2}\sin^{n-2}x\cos^2x\,dx
=(n-1)(I_{n-2}-I_n).
$$

故 $I_n=(n-1)I_{n-2}/n$。初值 $I_0=\pi/2,I_1=1$，从而 $I_2=\pi/4,I_3=2/3$。

递推不能在 $n=0$ 硬套。[2019-18](../questions/2019-301-18.md)记录其原递推分母为 $n+2$，但原积分未保留；本例是另一列自编积分，不能拿本例分母覆盖该纠错。
