# 配平方后使用反正切原函数

二次分母先提取首项系数，配成 $(x-h)^2+a^2$，确认 $a>0$，再令 $u=(x-h)/a$。若配方常数非正，应改查实零点和对数型积分，不能硬套反正切。

**自编例题。** 计算无穷上限积分

$$
I=\int_0^\infty\frac{dx}{x^2+2x+2}.
$$

分母为 $(x+1)^2+1$，在 $[0,R]$ 积分得 $\arctan(R+1)-\pi/4$。令 $R\to\infty$ 得 $I=\pi/4$。分母没有实零点，零端正常，无穷端极限有限，求值同时证明收敛。

[2021-11](../questions/2021-301-11.md)保留了配方结构但未保留系数，本例只示范动作。分子若含一次项，先拆成分母导数的倍数与常数，可能同时出现对数。
