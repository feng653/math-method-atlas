# 用局部积分平均检查间断点导数

被积函数在接点不连续时，写累积函数的差商 $h^{-1}\int_{x_0}^{x_0+h}f(t)dt$，分别算正、负 $h$ 的极限。积分不受单点值影响，所以导数可能不等于 $f(x_0)$。

**自编例题。** 令 $f(t)=1$（$t\ne0$）、$f(0)=9$，$F(x)=\int_0^xf(t)dt$。单点修改不改变积分，故 $F(x)=x$，差商恒为一，$F'(0)=1\ne f(0)$。

再令 $g(t)=0$（$t<0$）、$g(t)=1$（$t\ge0$），$G(x)=\int_0^xg$。右差商为一，左差商为零，故 $G$ 在零点连续但不可导。

两例说明“被积函数不连续”既不能直接推出累积函数不可导，也不能允许直接套基本定理。图像题中的单侧斜率同样要这样核对。
