# 分段积分上边界减下边界

先解交点并判断每段上下关系，再把竖直截段长度积分；若上下角色交换必须分段，或用绝对值。面积非负，不能让不同区域的符号抵消。

**真题已摘录片段的原创演算。** [2009-16](../questions/2009-301-16.md)保留 $[0,1]$ 上相邻幂曲线面积通项。对正整数 $n$，有 $x^n\ge x^{n+1}$，所以

$$
a_n=\int_0^1(x^n-x^{n+1})dx
=\left[\frac{x^{n+1}}{n+1}-\frac{x^{n+2}}{n+2}\right]_0^1
=\frac1{(n+1)(n+2)}.
$$

例如 $a_1=1/6$，两曲线只在零、一相交，整个内区间的上下关系一致。若后续从 $n=1$ 作有限和，则 $\sum_{n=1}^Na_n=1/2-1/(N+2)$；无限和及奇数子项属于原题的后续级数任务，不由此补造题目编号。

选择水平截段也可以，但必须改用右边界减左边界与 $dy$，不能只换变量名。
