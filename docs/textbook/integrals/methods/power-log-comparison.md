# 逐端匹配幂函数与对数幂阈值

有限零端的 $x^{-p}$ 在 $p<1$ 收敛，无穷端在 $p>1$ 收敛；临界指数一时再检查对数。把端点平移到零或用倒代换，不要凭分母幂次直接定结论。

**自编例题。** 判断 $\int_e^\infty dx/[x(\ln x)^q]$。令 $u=\ln x$，截断后成为 $\int_1^{\ln R}u^{-q}du$。当 $q\ne1$，它等于 $[(\ln R)^{1-q}-1]/(1-q)$；$q=1$ 时为 $\ln\ln R$。因此恰在 $q>1$ 收敛，值为 $1/(q-1)$。

另一个零端例子为 $\int_0^{e^{-1}}dx/[x|\ln x|^q]$。令 $u=-\ln x$ 后也成为 $\int_1^\infty u^{-q}du$，阈值同为 $q>1$，这是对数代换的结果，不是混淆有限端普通幂阈值。
