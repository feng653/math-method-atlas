# 由特征根实部证明解衰减和可积

常系数齐次方程的所有特征根实部严格为负时，解是有限个多项式乘衰减指数及三角因子的组合。选较小的衰减率 $\delta>0$，多项式因子可吸收到 $Ce^{-\delta x}$，由此同时控制函数与各阶导数。

**真题摘录演算。** [2020-11](../questions/2020-301-11.md)给出 $f''+af'+f=0,a>0$。特征根为

$$
r_{1,2}=\frac{-a\pm\sqrt{a^2-4}}2.
$$

当 $0<a<2$，共轭根实部为 $-a/2<0$；$a=2$ 为重根 $-1$，解为 $(C_1+C_2x)e^{-x}$；$a>2$ 时 $\sqrt{a^2-4}<a$，两实根都负。因此所有初值对应的 $f,f'$ 均趋零，且 $|f|$ 被可积衰减指数控制，反常积分绝对收敛。这为[积分方程求值](integrate-ode-boundary.md)准备了边界条件。

[2016-16](../questions/2016-301-16.md)只保留根 $-1\pm\sqrt{1-k}$。就该根式而言，$k>0$ 时全部实部负；$k=0$ 出现零根，$k<0$ 有正根，具体解仍可能因相应系数为零而衰减。原参数范围和初值未全，不能把这段分类冒充该题结论。
