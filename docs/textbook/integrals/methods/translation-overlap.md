# 平移积分区间并扣除重叠部分

当题给 $f(x+h)-f(x)$ 时，对关系在有效区间积分，再把前项令 $t=x+h$。两积分重叠的区间抵消，留下两端短段；不要把函数差关系误认成周期性。

**自编例题。** 连续函数在 $[0,3]$ 满足 $f(x+1)-f(x)=2x+1$（$0\le x\le2$）。求 $\int_2^3 f-\int_0^1 f$。积分关系给

$$
\int_0^2[f(x+1)-f(x)]dx=\int_0^2(2x+1)dx=6.
$$

左边为 $\int_1^3f-\int_0^2f=\int_2^3f-\int_0^1f$，所求即 $6$，无需确定 $f$ 本身。[2023-14](../questions/2023-301-14.md)的平移长度与差式缺失，本例的系数不能作为原题数据。
