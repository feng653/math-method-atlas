# 在有限区间换元或分部后取端点极限

先把无穷上限替换为 $R$，或把瑕点替换为 $\varepsilon$，在正常区间做代数操作。写出每个边界项与剩余积分的独立极限，只有有限总极限成立才获得收敛值。

**自编例题。** 求 $\int_1^\infty\ln x/x^2\,dx$。在 $[1,R]$ 取 $u=\ln x,dv=x^{-2}dx$，得到

$$
I_R=\left[-\frac{\ln x}x\right]_1^R+\int_1^R\frac{dx}{x^2}
=-\frac{\ln R}R+1-\frac1R\longrightarrow1.
$$

这里 $\ln R/R\to0$，剩余积分也有有限极限，所以求值合法。不能写“$\ln\infty/\infty=0$”代替极限论证。

[2026-14](../questions/2026-301-14.md)仅保留对数除以变量的边界衰减结构，原式未全，本例不冒充真题。对[2013-15](../questions/2013-301-15.md)更要保留零端检查，不能预先认定边界项消失。
