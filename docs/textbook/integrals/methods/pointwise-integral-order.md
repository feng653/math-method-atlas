# 将点态不等式传为严格积分比较

先统一积分区间，核对分母正负和积分存在性，再比较被积函数。要推出严格不等号，可证明差函数连续且在一个点严格为正，从而在邻近一段区间有正下界。

**自编例题。** 比较 $A=\int_0^1dx/(1+x^2)$ 与 $B=\int_0^1dx/(1+x)$。对 $0<x<1$，$x^2<x$，分母均正，故

$$
\frac1{1+x^2}-\frac1{1+x}
=\frac{x-x^2}{(1+x^2)(1+x)}>0.
$$

差函数连续并在整个内区间正，积分严格为正，因此 $A>B$，即 $\pi/4>\ln2$。端点差为零不妨碍严格结论。

一般可积函数仅在单个点严格为大，积分可能仍相等；不能漏掉正长度依据。[2022-04](../questions/2022-301-04.md)的具体分母缺失，本例不代表其排序。
