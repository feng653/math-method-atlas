# 核对正常区间后取原函数端点差

确认被积函数在有限区间可积，所选原函数连续到两端且内部导数正确，再计算 $F(b)-F(a)$。不定积分常数会抵消，不需要额外求它。

**自编例题。** 求 $\int_0^1(3x^2-2x+1)dx$。原函数 $F=x^3-x^2+x$ 在闭区间连续且 $F'=3x^2-2x+1$，于是

$$
I=F(1)-F(0)=1-1+1=1.
$$

对照 $\int_{-1}^1dx/x^2$，虽然 $-1/x$ 在两侧各是原函数，却不是穿过零点的原函数；机械端点差给出负数正说明前提失效。应拆为两个反常积分，均发散，不能应用本工具。
