# 用恒等式和半角变量有理化

先尝试倍角、降幂等恒等式；一般三角有理式可令 $t=\tan(x/2)$，代入 $\sin x=2t/(1+t^2)$、$\cos x=(1-t^2)/(1+t^2)$、$dx=2dt/(1+t^2)$。半角变量在奇数倍 $\pi$ 断开，必须按区间处理。

**自编例题。** 在 $(-\pi,\pi)$ 求 $\int dx/(2+\cos x)$。换元得

$$
\int\frac{2\,dt}{t^2+3}
=\frac2{\sqrt3}\arctan\frac{\tan(x/2)}{\sqrt3}+C.
$$

特别地，$0\le x\le\pi/2$ 对应 $0\le t\le1$，定积分为 $\pi/(3\sqrt3)$。原被积函数在 $x=\pi$ 仍正常，只是上述原函数表达式分支跳跃；跨该点时应分段匹配常数，不能直接拿跨支的端点值相减。
