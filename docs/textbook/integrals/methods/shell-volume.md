# 以半径和壳高累积圆柱壳体积

平行旋转轴切片，当每个半径只对应一个不重复的壳层时，用 $2\pi rh\,dr$。先确定半径是到轴距离，壳高是旋转后同半径截段的并集长度；跨轴时左右壳可能重合。

**自编例题。** 区域 $0\le x\le1,0\le y\le x$ 绕 $y$ 轴旋转。半径 $r=x$、高 $h=x$，各半径唯一，故

$$
V=2\pi\int_0^1x^2dx=\frac{2\pi}3.
$$

用水平圆环可核对：对 $0\le y\le1$，半径从 $y$ 到一，$V=\pi\int_0^1(1-y^2)dy=2\pi/3$。

若区域横跨 $y$ 轴，不能把左右两边的 $2\pi|x|h$ 无脑相加；同一半径若来自 $x$ 与 $-x$，必须合并实际高度，避免重复计算体积。
