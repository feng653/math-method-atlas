# 积分恢复局部函数并使用初值

已知 $f'$ 与一点函数值时，优先写 $f(x)=f(x_0)+\int_{x_0}^x f'(t)dt$。积分路径必须留在导数公式成立的区间；这同时避免漏常数。

**自编例题。** 已知 $f'(x)=2x/(1+x^2)$（$0\le x\le1$）及 $f(0)=0$，则

$$
f(x)=\int_0^x\frac{2t}{1+t^2}\,dt=\ln(1+x^2),\quad 0\le x\le1,
$$

故 $f(1)=\ln2$。没有更远处的导数信息时，不能据此声称 $f(3)=\ln10$。

[2014-10](../questions/2014-301-10.md)提供奇性，所以原函数在零点的初值为零；但局部导数式尚未保留，只能确定恢复函数的过程，不能补造数值。远点先用[周期归约](function-period-reduction.md)转回合法区间。
