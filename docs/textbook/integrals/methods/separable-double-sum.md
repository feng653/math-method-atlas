# 将乘积型双重和分成两个一维和

只有求和区域是直积且项可写成只含 $i$ 的因子乘只含 $j$ 的因子时，才能先在有限和层面分离，再分别用 Riemann 和。先完成精确代数恒等式，避免不必要的无限运算交换。

**自编例题。** 求

$$
\lim_{n\to\infty}\frac1{n^2}\sum_{i=1}^n\sum_{j=1}^n
\frac{i}{n}\left(\frac jn\right)^2.
$$

有限和恰等于 $[n^{-1}\sum_i(i/n)][n^{-1}\sum_j(j/n)^2]$。两个连续函数和的极限分别为 $\int_0^1x\,dx=1/2$ 与 $\int_0^1y^2dy=1/3$，故答案为 $1/6$。

若项为 $1/(1+i/n+j/n)$，通常不能作这样的乘积分离；若约束 $i+j\le n$，求和区域也不再是直积。[2010-04](../questions/2010-301-04.md)只保留分离结构，本例不是该题原和式。
