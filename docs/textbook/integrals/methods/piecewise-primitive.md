# 分段积分并核对接点导数

每个光滑分段先独立积分，给独立常数；要求接点连续以联系常数，再算接点差商是否等于被积函数指定值。连续拼起来只是第一关。

**自编例题。** 对 $f(x)=x$（$x<0$）、$f(x)=2x$（$x\ge0$）求原函数。两段分别是 $x^2/2+C_-$ 与 $x^2+C_+$。连续要求 $C_-=C_+=C$，而

$$
\frac{F(h)-F(0)}h=
\begin{cases}h/2,&h<0,\\h,&h>0\end{cases}\longrightarrow0=f(0).
$$

所以拼接成立。若只将 $f(0)$ 改为 $1$，段上积分和连续匹配都不变，但接点导数仍为零，便不存在满足要求的原函数。
