# 选择求导后变简单的因子分部

将乘积写成 $u\,dv$，使 $du$ 简化且 $v$ 易求；完整写出 $uv-\int v\,du$。定积分保留两个端点乘积，反常端必须先截断。

**自编例题。** 求 $\int_1^e x\ln x\,dx$。取 $u=\ln x,dv=x\,dx$，则 $du=dx/x,v=x^2/2$，所以

$$
\int_1^e x\ln x\,dx
=\left[\frac{x^2}2\ln x\right]_1^e-\frac12\int_1^e x\,dx
=\frac{e^2+1}{4}.
$$

这里下端第一个乘积为零，但第二个积分仍有下端贡献。[2022-12](../questions/2022-301-12.md)缺完整端点，不能把该材料直接当作同样的普通定积分；出现 $\ln0$ 时要用乘积极限另行处理。
