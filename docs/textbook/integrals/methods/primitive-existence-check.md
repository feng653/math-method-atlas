# 用连续性与介值性质检查原函数

先确定讨论的是一个连通区间上的原函数。被积函数在区间连续时，可直接用变上限积分构造原函数；有间断时，先检查是否违反导数的介值性质，不能把“不连续”当作不存在的充分证据。

**自编例题。** 令 $f(x)=0$（$x<0$）、$f(x)=1$（$x\ge0$）。若有 $F'=f$，那么 $F'(-1)=0$、$F'(1)=1$，导数介值性质要求某点的导数等于 $1/2$，与值域只有 $0,1$ 矛盾。因此不存在跨越零点的原函数，虽然 $f$ 在每个有限闭区间都可积。

对照 $g(x)=|x|$，它连续，逐段检查得到

$$
G(x)=\tfrac12x|x|,\qquad G'(0)=\lim_{h\to0}\tfrac12|h|=0,
$$

且非零点 $G'=|x|$，所以 $G+C$ 就是全部原函数。振荡间断是否能成为导数需要另查，不能沿用跳跃反证。
