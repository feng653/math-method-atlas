# 积分绝对值估计把点态界转成总误差

先把两个目标的差写成一个积分，再使用 $|\int e|\le\int|e|$。若已知 $|e(x)|\le g(x)$，只需计算 $\int g$；不能把积分绝对值误当成恒等于绝对值积分。

**自编例题。** 对 $f\in C^2[0,1]$、$|f''|\le M$，用端点线性插值 $L(x)=(1-x)f(0)+xf(1)$ 近似。由[点态插值界](taylor-interpolation-bound.md)，

$$
\left|\int_0^1f(x)dx-\frac{f(0)+f(1)}2\right|
\le\frac M2\int_0^1x(1-x)dx=\frac M{12}.
$$

取 $f=x^2$，真实差为 $|1/3-1/2|=1/6$，而 $M/12=2/12=1/6$，验证界可取等。

这里有界导数条件在整个区间成立，不能只在一个点成立。[2024-19](../questions/2024-301-19.md)的整体误差任务可读这一动作，但不得据此声称原题的完整常数已核验。
