# 对积分限逐层使用链式法则

被积函数在有关端点连续、上下限可导时，上端贡献是被积函数上端值乘上端导数，下端贡献带负号。继续求高阶导数时，端点值与乘子都要再求导。

**自编例题。** 令 $F(x)=\int_x^{x^2}\sin tdt$，则

$$
F'(x)=2x\sin(x^2)-\sin x,
\qquad F''(x)=2\sin(x^2)+4x^2\cos(x^2)-\cos x.
$$

所以 $F''(0)=-1$。即使 $x^2<x$，有向积分约定仍保证公式成立，无须自行对积分取绝对值。

[2011-11](../questions/2011-301-11.md)确定上限为 $xy$。若用符号 $H(s)=\int_a^s h(t)dt$ 表示其积分层，在 $h\in C^1$ 时 $\partial_y\partial_xH(xy)=h(xy)+xyh'(xy)$。这是确定结构下的通式，缺失的核及指定点不能由此补造。
