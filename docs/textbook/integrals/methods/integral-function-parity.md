# 反射变限积分并保留下限常数

对 $F(x)=\int_0^xf(t)dt$，将 $F(-x)$ 用 $t=-u$ 改写；若 $f$ 偶，则 $F$ 奇，若 $f$ 奇，则 $F$ 偶。区间须关于零对称，积分须存在。

**自编例题。** $f(t)=t^2$ 为偶函数，但 $G(x)=\int_1^xt^2dt=(x^3-1)/3$ 既非奇也非偶。真正的零下限函数是 $F(x)=x^3/3$，而 $G=F-1/3$；常数平移破坏奇性。

另取 $H(x)=\int_1^xtdt=(x^2-1)/2$，它仍为偶函数，因为给偶函数加常数不会改变偶性。由此可见不能把固定下限的影响笼统处理。
