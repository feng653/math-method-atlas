# 按周期拆段并保留权重变化

把长区间分成周期段，每段平移到基本区间。周期因子可复用，但 $x$、指数衰减等权重应改成平移后的表达式；半周期变号也必须保留。

**自编例题。** 求 $\int_0^{2\pi}x|\sin x|dx$。绝对正弦的周期为 $\pi$，第二段令 $x=t+\pi$，故

$$
I=\int_0^\pi(2t+\pi)\sin t\,dt.
$$

分部算得 $\int_0^\pi t\sin tdt=[-t\cos t]_0^\pi+\int_0^\pi\cos tdt=\pi$，且 $\int_0^\pi\sin tdt=2$，于是 $I=4\pi$。

这里 $x|\sin x|$ 本身并不周期。若直接用“一个周期积分乘二”，会漏掉第二段增加的权重。无穷多段还须另证所成级数收敛。
