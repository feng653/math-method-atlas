# 为积分序列建立可计算的趋零上界

找到 $|f_n|\le g_n$ 并算出 $\int g_n\to0$，即可夹逼 $\int f_n\to0$。上界必须可积，只有逐点趋零不足以交换极限与积分。

**自编例题。** 令 $I_n=\int_0^1x^n\ln(1+x)dx$。由 $0\le\ln(1+x)\le x$ 得

$$
0\le I_n\le\int_0^1x^{n+1}dx=\frac1{n+2}\longrightarrow0.
$$

故 $I_n\to0$，不必先求出其闭式。[2010-17](../questions/2010-301-17.md)确实保留了这个对数不等式，但未保留完整序列，本例明确为自编。

逐点论证的反例是 $f_n=n$（$0<x<1/n$），其他点为零且 $f_n(0)=0$。每点趋零，但 $\int_0^1f_n=1$；逐点极限没有控制移动且变高的尖峰。
