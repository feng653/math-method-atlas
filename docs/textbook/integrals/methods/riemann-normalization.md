# 从和式识别网格宽与采样点

先提出使求和项成为固定函数的倍率，再写 $\Delta x$、采样点和区间。连续函数的等分和可直接取积分极限；采样点若随 $n$ 改变，仍须落在对应小区间中。

**自编例题。** 求 $\lim_{n\to\infty}\sum_{k=1}^n n/(n^2+k^2)$。整理成

$$
\frac1n\sum_{k=1}^n\frac1{1+(k/n)^2}.
$$

这对应 $[0,1]$ 的右端采样点 $k/n$、宽度 $1/n$，函数 $1/(1+x^2)$ 连续，所以极限为 $\int_0^1dx/(1+x^2)=\pi/4$。

若把 $1/n$ 漏掉，原和式的规模就改变。题目中写成 $(2k-1)/(2n)$ 时是中点采样，不是宽度 $1/(2n)$；宽度仍由整个分割决定。[2021-04](../questions/2021-301-04.md)的选项未保留，不能凭此示例指定选项。
