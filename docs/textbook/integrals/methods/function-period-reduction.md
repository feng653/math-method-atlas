# 用周期和奇偶性把点移回已知区间

先用 $f(x+kT)=f(x)$ 把目标点平移到一个基本区间，再用 $f(-x)=\pm f(x)$ 放入局部公式有效域。每次变换都写在函数自变量上，不能直接把局部表达式当成全局公式。

**真题确定片段。** [2014-10](../questions/2014-301-10.md)摘录给出周期四、奇性和目标点可归约到 $-1$。对该目标 $x_*$，完整的确定链为

$$
f(x_*)=f(-1)=-f(1),\qquad f(0)=0.
$$

若局部导数完整给出，再用 $f(1)=\int_0^1 f'(t)dt$；此处不补缺失的被积函数。

**自编演算。** 若另设四周期奇函数在 $[0,1]$ 上为 $f(x)=x$，求 $f(7)$：$7-2\cdot4=-1$，故 $f(7)=-f(1)=-1$。这是相容的局部设定示例，不是该真题的数值答案。
