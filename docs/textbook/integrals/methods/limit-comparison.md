# 用正函数比值的正有限极限判同敛散

先把比较限制在同一个反常端附近，保证两函数正且局部可积。比值趋于 $L\in(0,\infty)$ 时，两侧可夹在固定正常数倍之间，从而同敛散。

**自编例题。** 判断 $\int_0^1(1-\cos x)x^{-p}dx$。因

$$
\lim_{x\downarrow0}\frac{(1-\cos x)x^{-p}}{x^{2-p}}=\frac12,
$$

与 $\int_0^1x^{2-p}dx$ 同敛散，条件为 $2-p>-1$，即 $p<3$。远离零点没有其他奇点；$p=3$ 恰落在对数发散边界。

若比值趋零，只能说“大者收敛推出小者收敛”；例如在无穷端 $x^{-2}/x^{-1}\to0$，前者收敛后者发散，不能同敛散。变号振荡函数先查[绝对收敛](absolute-convergence.md)或另用振荡判别。
