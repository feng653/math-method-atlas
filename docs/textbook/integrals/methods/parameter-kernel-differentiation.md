# 求导时同时处理积分核与积分限

在有限正常区间，核 $K$ 及参数偏导连续、积分限为 $C^1$ 是常用充分条件。先写上、下端边界贡献，再积分 $K_x$；不能只代入上限。

**自编例题。** 设 $F(x)=\int_0^x(x^2-t^2)e^t dt$。上端核为零，下端不动，所以

$$
F'(x)=0+\int_0^x2xe^tdt=2x(e^x-1),
\qquad F''(x)=2(e^x-1)+2xe^x.
$$

也可先拆成 $x^2\int_0^xe^tdt-\int_0^xt^2e^tdt$，乘积求导后的 $x^2e^x$ 正好抵消，验证没有漏边界项。

[2010-16](../questions/2010-301-16.md)保留类似消项结构，但参数与完整核缺失，本例为自编。无穷区间须另有一致收敛或控制条件，不能直接搬用有限区间公式。
