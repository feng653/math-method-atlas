# 由积分条件造出多个等值点并使用 Rolle

选择辅助函数，使题给积分变成它在几个点的值相同，再逐次用 Rolle。每次都要列出连续、可导区间；若目标是二阶导数零点，检查辅助函数导数与目标之间还隔几层。

**自编例题。** 设 $f\in C^2[0,3]$，且在 $[0,1],[1,2],[2,3]$ 三段积分都为零。令 $F(x)=\int_0^xf(t)dt$，则 $F(0)=F(1)=F(2)=F(3)=0$。

逐段 Rolle 给 $a_1\in(0,1),a_2\in(1,2),a_3\in(2,3)$，满足 $f(a_i)=F'(a_i)=0$。再在 $(a_1,a_2),(a_2,a_3)$ 得 $f'(b_1)=f'(b_2)=0$，最后在 $(b_1,b_2)$ 得 $f''(c)=0$。

从 $F$ 出发实际用了三层，不能误称“两次必得 $f''$”。[2026-20](../questions/2026-301-20.md)记录原题另造三点等值函数后两次 Rolle，但辅助函数条件未全，本例不替它补式。
