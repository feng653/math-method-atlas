# 沿有向位移积分力的切向分量

先选位置坐标和正方向，把力投影到运动方向，写 $dW=F(x)dx$；积分限描述真实起终点。力可以作负功，不能为求正数任意取绝对值。

**自编例题。** 弹簧劲度系数 $k=100\,\mathrm{N/m}$，从自然长度缓慢拉长 $0.2\,\mathrm m$。忽略动能变化时外力 $F(x)=kx$，外力功为

$$
W=\int_0^{0.2}100x\,dx=50(0.2)^2=2\,\mathrm J.
$$

弹簧力为 $-kx$，它在同一位移上作功 $-2\,\mathrm J$。若缓慢回到自然长度，外力仍沿正向抵抗回缩，而 $dx<0$，外力功为 $-2\,\mathrm J$。

若力还依赖时间、速度或运动路径，必须先沿给定运动表达切向力，不能仅凭端点套一元位置公式。单位核对为牛顿乘米。
