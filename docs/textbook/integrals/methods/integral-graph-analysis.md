# 结合导数符号和累积面积判断图像

先标定累积函数在下限的值零，再用连续段 $F'=f$ 判断增减；极值看符号改变，零点看已累计的正负面积是否抵消。$f$ 的零点并不自动是 $F$ 的零点。

**自编例题。** $F(x)=\int_0^x(t-1)dt$，$0\le x\le3$。因 $F'=x-1$，它在 $[0,1]$ 下降，在 $[1,3]$ 上升。直接累计得

$$
F(x)=\frac{x^2}2-x,\quad F(1)=-\frac12,\quad F(x)=0\iff x=0\text{ 或 }2.
$$

所以 $x=1$ 是最低点而不是零点；到 $x=2$ 后正面积才抵消先前负面积。又 $F''=1>0$，图像一直向上弯。
