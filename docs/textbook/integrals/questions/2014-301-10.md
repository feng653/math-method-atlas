# 2014 年数学一第 10 题：局部积分与周期取值

由局部导数恢复函数，再利用奇性与周期求远处函数值。旧说明记录周期为四，目标点可先归约到负一，再用奇性转到已知正点。

归入[由导数与周期求函数值](../problem-types/recover-function/index.md)。奇性提供零点初值；局部积分得到的表达式不能直接延伸到全实轴。
