# 2009 年数学一第 17 题：旋转曲面间体积

既有摘录区分两问：构造旋转曲面方程，以及计算其间体积。椭圆与切线的旋转决定内外边界，体积应由垂直旋转轴的截面积差累积。

本章对应[体积计算](../problem-types/volume/index.md)；曲面方程构造是空间几何任务。椭圆参数、切点及界限未完整保留，不补写体积数值。
