# 2012 年数学一第 4 题：半周期积分比较

指数权重乘正弦的积分比较。按半周期平移后，正弦变号而指数权重增大，因此相邻有向面积不能按纯正弦的周期性直接抵消。

归入[积分比较](../problem-types/integral-comparison/index.md)，可参看[周期拆分入口](../problem-types/integral-identities/index.md)。具体区间与选项尚未在本文恢复。
