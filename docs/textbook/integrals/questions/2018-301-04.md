# 2018 年数学一第 4 题：三个积分比较

对称区间上先消去奇项，再比较剩余被积函数。旧摘录指出一个积分化为圆周率，另一个含严格为正的余项，第三个可借指数函数不等式严格压低。

归入[积分比较](../problem-types/integral-comparison/index.md)。严格性的理由应落实到区间而非单点；完整三式尚未在本文恢复。
