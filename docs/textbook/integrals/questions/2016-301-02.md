# 2016 年数学一第 2 题：分段原函数拼接

先在不同区间积分，其中对数部分需要分部；再用接点条件联系各段积分常数。摘要未给出完整分段函数，不能只凭连续拼接宣称可导。

归入[原函数存在与拼接](../problem-types/primitive-existence/index.md)。恢复题面后须检查两侧导数与接点被积函数值。
