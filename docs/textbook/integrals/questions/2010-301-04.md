# 2010 年数学一第 4 题：可分离双重和极限

双重和的结构可拆成两个一维 Riemann 和的乘积，也可用单位正方形上的累次积分解释。这里保留作答结构，不复制旧题面。

归入[求和极限](../problem-types/riemann-limit/index.md)。可分离性须由求和项的乘积结构证明；一般双重和不能按此路线强拆。
