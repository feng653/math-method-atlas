# 2010 年数学一第 16 题：含参变限积分极值

积分核与上限均含变量，要求判断所得函数极值。旧说明给出可先拆成变量平方乘一个变上限积分，再减另一变上限积分的结构；求导后端点项相消。

归入[积分函数极值](../problem-types/integral-function/index.md)，中间步骤见[变限求导](../problem-types/variable-derivative/index.md)。不是只把上限代入被积函数就完成求导。
