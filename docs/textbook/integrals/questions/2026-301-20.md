# 2026 年数学一第 20 题：积分正性与二阶导零点

旧记录分两问：证明半区间积分严格为正，以及证明二阶导数存在零点。前一问用严格单调性比较两半积分；后一问构造三点等值的函数后两次使用 Rolle 定理。

分别归入[积分严格比较](../problem-types/integral-comparison/index.md)和[由积分条件证明零点存在](../problem-types/integral-existence/index.md)。辅助函数与光滑条件未完整保留，本文不给缺条件的存在性证明。
