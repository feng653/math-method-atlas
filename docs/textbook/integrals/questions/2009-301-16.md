# 2009 年数学一第 16 题：面积级数求和

先求相邻幂曲线间的面积，再求全项及奇数子项的和。既有摘录保留面积通项：

$$
a_n=\int_0^1(x^n-x^{n+1})\,dx=\frac1{n+1}-\frac1{n+2}.
$$

归入[平面面积](../problem-types/plane-area/index.md)。面积建模之后的有限部分和、裂项及幂级数处理属于级数章；不能把两个未编号目标当成两道题，也不需要先交换无限求和与积分。
