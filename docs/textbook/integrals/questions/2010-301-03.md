# 2010 年数学一第 3 题：端点反常积分

任务涉及根式层级和两个端点的可积性。旧摘录指出零端比较幂为下式，参数为正整数；另一端有对数幂奇性：

$$
\frac2m-\frac1n.
$$

归入[反常积分敛散](../problem-types/improper-convergence/index.md)。需分别恢复两端局部等价式；缺少原被积函数，本文不据该指数补造题面或选项。
