# 2023 年数学一第 14 题：区间平移积分

利用给定函数差关系求积分。将区间平移后，扣除重叠区间，可把未知积分差变成可计算部分。

归入[函数关系与积分恒等式](../problem-types/integral-identities/index.md)。原式没有完整保留，不假定函数周期性，也不补造平移长度。

[来源：郑州工商学院托管 PDF，物理第 3 页第 14 题](https://www.ztbu.edu.cn/uploadfile/files/2023/05/07/20230507174051089.pdf)。本轮未重查来源，函数差在哪些区间成立仍需原题确认。
