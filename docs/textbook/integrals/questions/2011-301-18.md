# 2011 年数学一第 18 题：对数界与调和和数列

旧记录第一问要求证明对数严格双边界，第二问研究调和和减对数的收敛。前一任务可把对数差写成倒数函数在相邻整数区间的积分，利用严格单调性夹界。

本章对应[积分比较](../problem-types/integral-comparison/index.md)。后续用相邻差及下界证明数列单调有界，是数列章任务；不需要假设它来自自治递推。
