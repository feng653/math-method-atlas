# 2012 年数学一第 18 题：参数曲线及无界面积

切线横截距的距离条件用于确定参数曲线。旧摘录保留：

$$
x=f(t),\quad y=\cos t,\quad 0\le t<\frac\pi2,
\qquad f'(t)=\frac{\sin^2t}{\cos t}.
$$

本章对应[平面面积](../problem-types/plane-area/index.md)。对每个内部截点先积分，再令参数趋端点；虽然横坐标趋无穷，面积可有有限极限。正导数决定参数方向。

[来源：社区整理页，第 18 题](https://www.csgraduates.com/study_methods/math/math1/2012/#18)。公式来自旧完成度复审摘录，本轮未重查；切线模型的完整条件仍需原题，不能误称有限闭区域。
