# 一元函数积分学：概念交接

概念稿位于 [concepts.md](concepts.md)。本阶段只新增这两篇 Markdown，未访问网站代码或内容 JSON，未运行项目程序。采用多元微分新稿的短段落、独立公式与条件紧邻结论的表达方式。

## 交给题型作者

以下按作答目标划分候选题型，不表示有对应真题或已核验课纲。请先从主 agent 提供的既有来源确认题目，再确定实际保留的入口：

- 判断原函数存在性、不定积分常数与定义域。
- 计算不定积分；求含初值的原函数。
- 计算普通定积分；由 Riemann 和识别积分极限。
- 求变限积分导数与高阶导数；处理间断点处可导性。
- 由积分定义的函数求极限、单调性、极值或方程关系。
- 证明积分恒等式、不等式或积分中值结论。
- 判断反常积分敛散性；确定参数取值范围。
- 计算收敛反常积分；区分普通收敛与主值。
- 求平面面积、旋转体或已知截面积的体积、弧长。
- 建立功、质量、质心、位移与路程的积分模型。

换元与分部不是题型名称；它们可以服务多个题型。被积函数含参求导可作为变限积分工具的条件扩展，是否单列题型由实际材料决定。

## 交给后续方法作者的候选工具

请由题型作者结合实际题目裁定粒度，第三阶段才开始写工具文章。

1. 凑微分与直接原函数识别。
2. 三角、根式与倒代换；每一种写明分支及积分范围。
3. 有理函数部分分式分解后逐项积分。
4. 单次分部、递推分部与循环分部；不把三者压成只含口号的一篇。
5. 奇偶性、对称代换与周期拆分。
6. Riemann 和的网格与归一化识别。
7. 变上限原函数求导、双变限链式求导与积分差商。
8. 积分保序、绝对值估计与加权中值定理。
9. 瑕点逐个拆分、幂函数比较与极限比较。
10. 绝对收敛检查与 Dirichlet 振荡收敛判别。
11. 截断后分部或换元并核验边界极限。
12. 面积分段、截面积法、圆环法、圆柱壳法、参数弧长与微元建模。

每种工具需完整自编演算或已核验真题演算，交代触发条件、关键操作及失效边界。不得把未经细分复核的旧大类关联转成新工具已核验关联。

## 主审应重点复核

- 原函数常数按连通区间确定；可积、连续、有原函数三者不混同。
- 普通定积分要求闭区间有界；变上限积分连续与其可导使用不同条件。
- Newton–Leibniz 使用端点连续的原函数；反常端点不得直接代入。
- 本稿的定积分换元恒等式不要求单调，反解代换需一一对应分支。
- 反常积分逐端收敛；对称主值不能替代它。比较判别局限非负情形，振荡工具另列。
- 极坐标面积防重复覆盖；壳法限定轴一侧且无重复体积，参数弧长按遍历次数计长。
- 最新考纲、来源权威性和真题方法关联均未在本阶段核验。结构检查、公式渲染、链接检查与生产构建由主 agent 统一完成。
