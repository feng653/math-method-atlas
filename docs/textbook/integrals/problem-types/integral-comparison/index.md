# 比较积分大小及证明严格不等式

先把区间统一，再比较被积函数。严格不等式需要差函数在正长度区间上严格为正等依据，不能只凭单点严格。

工具：[点态保序与严格积分比较](../../methods/pointwise-integral-order.md)、[对称消奇项](../../methods/parity-integral.md)、[半周期拆分配对](../../methods/periodic-splitting.md)、[用可积界夹逼](../../methods/integral-squeeze.md)。反常端先确认有关积分收敛。
