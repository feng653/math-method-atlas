# 把求和极限化成定积分

必须同时识别网格宽、采样点、覆盖区间与外部倍率。双重和只有确实可分离时才化为两个一维和的乘积。

工具：[识别归一化 Riemann 和](../../methods/riemann-normalization.md)、[分离乘积型双重和](../../methods/separable-double-sum.md)。积分出现后再选[单次分部](../../methods/parts-once.md)等计算工具。

对照：[2010-04](../../questions/2010-301-04.md)、[2017-16](../../questions/2017-301-16.md)、[2021-04](../../questions/2021-301-04.md)。
