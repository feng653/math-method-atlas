# 计算有限区间定积分

先确认闭区间无未处理奇点，再选择原函数路线；换元必须连同上下限，分部必须保留边界项。遇见变上限积分嵌套时，可将内层积分作为一个函数，而非强求它的初等表达式。

- [用原函数作端点差](../../methods/newton-leibniz-evaluation.md)：核对端点连续性。
- [幂代换消根式](../../methods/radical-substitution.md)、[三角代换消二次根式](../../methods/trig-substitution.md)：根据根式结构选择。
- [单次分部](../../methods/parts-once.md)：对数、反三角或导数积分适用时降低复杂度。
- [以变限积分为分部因子](../../methods/nested-integral-parts.md)：导数能恢复已知被积函数；奇点处先截断。

对照：[2010-10](../../questions/2010-301-10.md)、[2012-10](../../questions/2012-301-10.md)、[2018-10](../../questions/2018-301-10.md)。[2013-15](../../questions/2013-301-15.md)存在零端核验要求，另见反常求值入口，不默认是普通定积分。
