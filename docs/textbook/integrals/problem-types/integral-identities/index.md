# 利用对称性、周期与函数关系求积分

没有初等原函数时仍可能求出积分。比较同一区间上变换前后的积分，找奇项消去、互补求和或区间重叠关系。

- [对称区间消去奇函数部分](../../methods/parity-integral.md)：先确认可积，反常积分不得用主值冒充收敛。
- [关于区间中点反射并配对积分](../../methods/reflection-pairing.md)：代换后区间保持相同，比较两被积函数之和。
- [平移区间并消去重叠部分](../../methods/translation-overlap.md)：已知函数差关系能在所需区间使用。
- [按周期或半周期拆分积分](../../methods/periodic-splitting.md)：权重未必周期，须保留每段变化。

对照：[2015-10](../../questions/2015-301-10.md)、[2023-14](../../questions/2023-301-14.md)。比较任务另见[2012-04](../../questions/2012-301-04.md)、[2018-04](../../questions/2018-301-04.md)。
