# 求显式、参数或极坐标曲线弧长

根据曲线表达方式建立速度模积分，先求导再化简平方根。参数重复遍历会重复计长，奇点处须判断反常长度是否收敛。

工具：[显式图像弧长积分](../../methods/graph-arc-length.md)、[参数及极坐标速度模求弧长](../../methods/parametric-arc-length.md)。变限积分定义的曲线先用[变限链式求导](../../methods/variable-limit-chain.md)。

对照：[2011 年第 9 题](../../questions/2011-301-09.md)。
