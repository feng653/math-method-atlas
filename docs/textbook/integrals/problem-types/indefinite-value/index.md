# 求不定积分或带初值的原函数

目标是得到可求导验证的原函数。先看复合结构和微分因子，再看有理分式、根式、三角式或乘积；初值最后用来确定所在连通区间的常数。

- [直接识别原函数并凑微分](../../methods/direct-differential.md)：内函数导数已经出现或只差常数。
- [部分分式分解后积分](../../methods/partial-fractions.md)：先作多项式除法，再按实因子分解。
- [配平方并使用反正切原函数](../../methods/quadratic-completion.md)：二次分母无实零点且配方常数为正。
- [幂代换消去根式](../../methods/radical-substitution.md)：选择实值分支并写出定义域。
- [三角代换消去二次根式](../../methods/trig-substitution.md)：先配方，控制三角变量区间。
- [倒代换化简倒数结构](../../methods/reciprocal-substitution.md)：区间不跨零，注意方向。
- [三角恒等式与正切半角有理化](../../methods/trig-rationalization.md)：分支断点须分区间处理。
- [单次分部降低乘积复杂度](../../methods/parts-once.md)、[循环分部解积分方程](../../methods/parts-cycle.md)：分别适用于求导后简化、或再次出现原积分的结构。

本批“有理积分”“反三角积分”摘录未明确有无上下限，见[待细分材料](../pending-classification/index.md)。不能凭方法名称把它们直接认定为不定积分真题。
