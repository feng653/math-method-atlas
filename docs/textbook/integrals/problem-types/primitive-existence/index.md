# 判断原函数存在性与分段拼接

先区分“有原函数”与“能写出初等原函数”。分段表达式在各开区间积分以后，还必须检查接点是否能成为同一个可导函数，只有连续拼接未必足够。

- [用连续性与导数介值性质检查原函数存在性](../../methods/primitive-existence-check.md)：连续给充分条件，跳跃可排除存在；其他间断不能据此直接下结论。
- [分段积分并匹配常数和接点导数](../../methods/piecewise-primitive.md)：先匹配函数值，再核对接点导数是否等于被积函数的指定值。

[2016 年第 2 题](../../questions/2016-301-02.md)提供分段原函数材料。不能从该题推断任意分段函数都能拼接。
