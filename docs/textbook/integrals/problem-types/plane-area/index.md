# 求平面有限或无界区域面积

先确定区域及积分方向，面积必须非负。曲线交点或正负号变化处需要分段；参数曲线要保留坐标微分，极坐标要防重复覆盖。

工具：[分段积分上下边界差](../../methods/cartesian-area.md)、[参数曲线面积换元](../../methods/parametric-area.md)、[极坐标扇形微元求面积](../../methods/polar-area.md)、[截断无界区域并累加分段面积](../../methods/unbounded-area-sum.md)。

对照：[2009-16](../../questions/2009-301-16.md)、[2012-18](../../questions/2012-301-18.md)、[2019-17](../../questions/2019-301-17.md)。2009-16 的级数求和与 2012-18 的切线建模属于跨章后续或前置步骤。
