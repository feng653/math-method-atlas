# 求旋转体或已知截面的体积

先确定切片方向与真实截面，再积分。旋转轴不一定是坐标轴，半径应写成到轴的距离；圆环外半径不能小于内半径。

工具：[截面积切片累积体积](../../methods/cross-section-volume.md)、[圆盘圆环法](../../methods/washer-volume.md)、[圆柱壳法](../../methods/shell-volume.md)。壳层不能重叠计数，跨轴区域应先重整。

对照：[2009 年第 17 题第二问](../../questions/2009-301-17.md)。曲面方程构造在空间几何章处理，不能把体积公式当成全部解法。
