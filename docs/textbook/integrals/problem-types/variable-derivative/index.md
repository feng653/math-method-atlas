# 求变限积分的一阶及高阶导数

辨认积分限与被积函数分别依赖哪些变量。只变上下限时用链式法则；核也依赖参数时必须补上积分内导数项。高阶导数每一步重新检查可导条件。

- [变上限与双变限链式求导](../../methods/variable-limit-chain.md)。
- [对参数核求导并保留边界项](../../methods/parameter-kernel-differentiation.md)：连续偏导是正常有限区间的常用充分条件。
- [用积分差商检查间断点导数](../../methods/integral-difference-quotient.md)：不能直接把间断点函数值代入基本定理。

对照：[2011-11](../../questions/2011-301-11.md)是二元复合求导中的一元积分步骤；[2010-16](../../questions/2010-301-16.md)最终要求极值，求导是中间操作。
