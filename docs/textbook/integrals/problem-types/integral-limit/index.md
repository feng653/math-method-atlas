# 求积分平均或积分序列的极限

积分含有参数不等于可以交换极限和积分。先找与参数有关、能够整体积分的上下界；无穷区间平均值可将固定首段与远端分开估计。

工具：[以可积界夹逼积分序列](../../methods/integral-squeeze.md)、[分离固定首段估计积分平均极限](../../methods/tail-average-estimate.md)。若求相邻积分比值，转到[递推入口](../integral-recurrence/index.md)。

对照：[2010-17](../../questions/2010-301-17.md)、[2025-03](../../questions/2025-301-03.md)。平均极限必须先确认首段积分存在。
