# 证明积分误差界

先控制近似函数与原函数的逐点差，再积分绝对值上界。点态估计和整体误差是两个任务，后者不能替代前者的证明。

工具：[用 Taylor 余项建立点态插值误差](../../methods/taylor-interpolation-bound.md)、[积分绝对值估计传递误差界](../../methods/absolute-integral-bound.md)。余项所需导数条件必须在整个相关区间成立。

对照：[2024 年第 19 题](../../questions/2024-301-19.md)，来源存在端点条件排印冲突，按题目页保留边界。
