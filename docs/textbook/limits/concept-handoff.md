# 函数、极限与连续：概念阶段交接

概念文章见 [concepts.md](concepts.md)。本阶段只写该文与交接说明；未访问代码、内容 JSON 或真题索引，未建立方法文章，未运行项目程序。文中例子均为自编说明，没有新增真题身份或方法核验声明。

## 已建立的概念边界

文章依次引入函数、邻域、数列极限、函数极限、单侧与无穷、有限极限运算、存在准则、无穷小比较、基本极限、不定式、连续间断及闭区间性质。采用相对于定义域的极限定义，普通双侧与单侧口径另外说明。

单调有界数列准则与单调函数的单侧极限分开。海涅准则强调所有趋近数列，柯西准则强调任意两项；有限极限与无穷大明确区分。同阶采用比值趋于非零有限常数的口径，不能把大 O 自动解释为同阶。

一致连续性只作为闭区间连续性质的补充说明；没有宣称其为已核验考试要求。导数、洛必达法则与泰勒公式的定义和定理应留在相应章节，本章题型若使用这些工具，应明确先修与条件。

## 给第二阶段作者的题型建议

题型按求解目标拆分，避免把所有内容塞入“求极限”。可考虑：确定函数定义域与复合关系；求反函数及限制区间；判断奇偶、周期、单调和有界；用定义证明指定极限；求有限点函数极限；求单侧与无穷远极限；求数列极限；证明递推数列收敛并求值；判断极限不存在；比较无穷小阶与求等价量；由极限条件确定参数；判断分段函数连续性并补定义；识别间断点及类型；证明方程零点存在或唯一；运用闭区间性质作存在性判断。

具体题型可在查到实际题目后调整；不要仅按表达式长相大量复制入口。一个参数题可能同时要求消去发散项和匹配余项，宜保留一个任务入口并列出选择工具的信号。

真题只使用主 agent 提供或已独立核对的题面与来源。年份、卷种、题号、表达式均不得推测；仅有旧摘要时保留摘要状态。来源可访问、题面已整理、方法适用已核验是三个不同结论。

## 建议的工具粒度

可分别提出连续性代入、左右极限拆分、因式分解消去、根式有理化、分子分母同除主导量、等价因子替换、夹逼估计、三角基本极限归一化、指数型取对数、变量替换、递推区间不变性、单调有界收敛证明、递推极限方程、奇偶子列分离、海涅数列反证、无穷小比值定阶、去心极限补连续、零点定理与单调唯一性。

“递推极限方程”必须接在收敛证明之后，并核对递推映射在候选极限处连续；不要把猜根当作存在性证明。指数型取对数要求底数在所用范围严格为正，等价替换必须区分乘除与相减消去。

洛必达、泰勒和 Stolz 等工具若确实为题目所需，可向第三阶段作者提出，但应标明它们各自的先修及适用条件，避免将所有不定式统一归于一个“套公式”工具。也不要因本章出现工具引用，就重写后续章概念。
