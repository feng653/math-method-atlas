# 求含积分的极限或积分数列极限

先判断积分本身是否存在。局部变上限问题可从被积函数的阶推积分阶；存在逐点不等式时可先积分估计。选择洛必达时还须核对变上限原函数可导及对应商型。

可选工具：[变上限积分局部定阶](../../methods/integral-local-order.md)、[积分不等式估计](../../methods/integral-comparison.md)、[夹逼估计](../../methods/squeeze-estimate.md)、[零比零型洛必达](../../methods/lhopital-zero.md)、[分母无穷型洛必达](../../methods/lhopital-infinite-denominator.md)、[泰勒展开保留首个未消项](../../methods/taylor-leading-term.md)。
