# 求主项相消后的差式极限

两个大项相减或低阶小量相消时，先在原式中完成代数整理，再保留首个未消项。分别把每项替换为首阶等价量通常会丢掉答案。

可选工具：[泰勒展开保留首个未消项](../../methods/taylor-leading-term.md)、[因式分解约去零因子](../../methods/factor-cancellation.md)。
