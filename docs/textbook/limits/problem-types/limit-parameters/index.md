# 由极限或等价条件确定参数

先用目标阶数迫使较低阶系数消失，再匹配首个保留项。求出参数后代回检查余项、定义域和题设极限；幂式先取对数，但不能省略最后还原。

可选工具：[低阶消项与系数匹配](../../methods/coefficient-matching.md)、[泰勒展开保留首个未消项](../../methods/taylor-leading-term.md)、[正底数幂取对数](../../methods/logarithm-power.md)。
