# 从尾部函数极限求积分平均极限

有限首段积分存在，才可讨论从固定端点开始的平均。把首段和尾段分开，首段除增长区间长度消失；尾段误差由函数极限控制。可导条件合适时也能选择分母无穷型洛必达。

可选工具：[积分平均值尾部估计](../../methods/integral-average-tail.md)、[分母无穷型洛必达](../../methods/lhopital-infinite-denominator.md)。
