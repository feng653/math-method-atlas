# 找间断点并判断类型

先列出表达式或分段发生变化的候选点，再判断每点两侧有限极限。共同有限极限与点值不符是可去情形；左右不等是跳跃；振荡或无穷需另区分。

可选工具：[左右极限拆分](../../methods/one-sided-split.md)、[按单侧极限分类间断](../../methods/discontinuity-classification.md)、[构造子列否定极限](../../methods/subsequence-counterexample.md)。
