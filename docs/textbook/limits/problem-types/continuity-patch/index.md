# 补定义或确定分段连续参数

先算拼接点两侧极限，再让共同极限等于点值。只有一侧存在定义域时按相应单侧判断。原函数拼接还涉及导数要求，连续匹配只是本章处理的必要环节。

可选工具：[左右极限拆分](../../methods/one-sided-split.md)、[等价因子替换](../../methods/equivalent-factor.md)、[共同极限匹配点值](../../methods/continuity-patching.md)。
