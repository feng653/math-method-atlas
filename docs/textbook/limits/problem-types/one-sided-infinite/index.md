# 求单侧或无穷远极限

绝对值、分段或符号变化先分方向；无穷远有不同增长幂次时同除主导量。把无穷远换成零点附近时，需要同步改写趋近方向。

可选工具：[左右极限拆分](../../methods/one-sided-split.md)、[同除主导量](../../methods/dominant-scaling.md)、[极限变量替换](../../methods/variable-substitution.md)。
