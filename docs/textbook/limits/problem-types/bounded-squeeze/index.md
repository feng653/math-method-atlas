# 用有界性或上下界确定极限

振荡因子未必有极限，但若最终有界，乘无穷小仍趋零。若不能拆成这种乘积，就寻找同极限的上下界；有界本身不足以证明收敛。

可选工具：[有界量乘无穷小](../../methods/bounded-times-zero.md)、[夹逼估计](../../methods/squeeze-estimate.md)。
