# 由复合数列极限反推内层极限

能否反推取决于内层取值范围与外层是否可逆。连续严格单调的外函数可在像区间用反函数传递极限；平方、余弦等多对一映射不能凭函数值恢复原项的符号或分支。

可选工具：[连续反函数传递极限](../../methods/inverse-continuity.md)、[限制区间求反函数](../../methods/inverse-branch.md)。
