# 求变底变指数的幂极限

底数在所用邻域必须为正。先把幂写成指数函数，求指数中的乘积极限；若目标还含幂与 1 的差，必须先证明新指数趋零，才能替换这个整体差。

可选工具：[正底数幂取对数](../../methods/logarithm-power.md)、[等价因子替换](../../methods/equivalent-factor.md)、[泰勒展开保留首个未消项](../../methods/taylor-leading-term.md)。
