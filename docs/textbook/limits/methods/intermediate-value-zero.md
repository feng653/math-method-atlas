# 连续函数异号取零点

要证明某方程至少有一个实根，先把它写为 $F(x)=0$，找到一个闭区间使 $F$ 在整个区间连续，且两端严格异号。介值定理给出内部零点，不要求会算出根。

**自编例题。** 证明方程 $x^3+x-1=0$ 在 $(0,1)$ 内有根。

令 $F(x)=x^3+x-1$。多项式在 $[0,1]$ 连续，且

$$
F(0)=-1<0,\qquad F(1)=1>0.
$$

因此存在 $c\in(0,1)$，使 $F(c)=0$。还可缩小区间：$F(1/2)=-3/8<0$，$F(3/4)=11/64>0$，故有根落在 $(1/2,3/4)$。

易错处是只验端点而不验整段连续。例如 $1/x$ 在 $-1,1$ 异号，却没有零点，因为跨过零点时不连续。若要求唯一，需要进一步[单调区间数根](monotonicity-root-count.md)，不能把“至少一个”写成“恰有一个”。
