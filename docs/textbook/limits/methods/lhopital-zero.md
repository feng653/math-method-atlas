# 零比零型洛必达

本工具以微分学为先修。在所讨论的一侧去心区间上，若 $f,g$ 可导，$f,g\to0$，$g'(x)\ne0$，且 $f'/g'$ 存在有限或扩展实数极限 $L$，则 $f/g\to L$。双侧题可分别核对两侧；反复使用时每一轮都须重新核对条件。

**自编例题。** 求 $\lim_{x\to0}(e^x-1-x)/x^2$。

分子分母都趋零，在去心邻域可导，分母导数 $2x\ne0$。导数商仍为零比零：

$$
\frac{e^x-1}{2x}.
$$

这一次分母导数是 $2\ne0$，再次求导后的商 $e^x/2\to1/2$。因此先由第二轮得到导数商趋于 $1/2$，再由第一轮得到原极限为 $1/2$。

易错处是对乘积或差式直接“上下求导”，或者导数商没有极限便判原极限不存在。洛必达是充分工具，不是逆向判据；可尝试[泰勒展开](taylor-leading-term.md)。数列不能直接求导，只有先建立适用的连续变量函数极限，再沿整数点取值，才可用于对应数列。
