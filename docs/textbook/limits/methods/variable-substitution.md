# 极限变量替换

换元把复杂内层变成标准小量时，要同时记录新变量的趋向、方向和定义域。若外函数只知道去心极限，还须保证内层最终不等于那个极限点；若外层在该点连续，就没有这一额外障碍。

**自编例题。** 求

$$
\lim_{x\to+\infty}x\sin\frac2x.
$$

令 $t=2/x$，则 $t\downarrow0$ 且 $x=2/t$，从而

$$
x\sin\frac2x=2\frac{\sin t}{t}\to2.
$$

这里 $t>0$ 且不为零，完全落在标准比值的合法范围。

为什么要管“取到极限点”？设 $F(t)=1$（$t\ne0$），但 $F(0)=7$。虽然 $\lim_{t\to0}F(t)=1$，取 $g(x)\equiv0$ 却有 $F(g(x))\equiv7$。只知道 $g(x)\to0$ 并不足够。

易错处还包括将 $x\to-\infty$ 换成 $1/x\downarrow0$，正确方向应为从负侧趋零。外层连续时用[连续性代入](continuity-substitution.md)更直接。
