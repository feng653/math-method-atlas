# 按单侧极限分类间断

在两侧去心邻域均有定义的点，先求左右极限，再检查点值。两侧有限相等但点值缺失或不相等是可去间断；两侧有限不等是跳跃间断；至少一侧无有限极限属于第二类，可再说明无穷或振荡。

**自编例题。** 分类 $f(x)=1/(1-e^{1/x})$ 在 $0$ 的间断。

对 $x\ne0$，$e^{1/x}\ne1$，故两侧均有定义。当 $x\downarrow0$ 时，$e^{1/x}\to+\infty$。同除指数得到

$$
f(x)=\frac{e^{-1/x}}{e^{-1/x}-1}\to0.
$$

当 $x\uparrow0$ 时，$1/x\to-\infty$，所以 $e^{1/x}\to0$，从而 $f(x)\to1$。两侧有限但不相等，故零点是跳跃间断，补点值无效。

易错处是看见表达式含 $1/x$ 就判无穷间断；应判断整个函数的单侧极限。若两侧相同，再用[连续补点](continuity-patching.md)判断能否消除间断；若振荡难以直接描述，可用[子列反例](subsequence-counterexample.md)。
