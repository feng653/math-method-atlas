# 2016-301-02：拼接原函数

先分段积分，对数部分还需分部积分，然后令原函数在拼接点连续。本章只处理左右极限和积分常数的连续匹配；完整原函数判定还需要核对拼接点导数与原被积函数，不以连续性替代原函数定义。

学习入口：[补定义或确定分段连续参数](../problem-types/continuity-patch/index.md)。
