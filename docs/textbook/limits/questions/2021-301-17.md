# 2021-301-17：变限积分差式极限

分式先通分，积分与指数展开后消去主项；分母各为一阶小量，需要保留抵消后的主部。积分展开应控制余项，不能把逐阶积分当作无条件的形式操作。

学习入口：[求主项相消后的差式极限](../problem-types/cancellation-limit/index.md)、[求含积分的极限或积分数列极限](../problem-types/integral-limit/index.md)。
