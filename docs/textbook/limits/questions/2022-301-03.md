# 2022-301-03：复合数列极限

既有记录给出余弦项取值在 $[0,1]$，正弦在此区间连续严格单调，可以使用连续反函数传递极限。这里的 $[0,1]$ 是该题记录的取值约束，并非余弦的一般值域；结论不能恢复原数列符号。
