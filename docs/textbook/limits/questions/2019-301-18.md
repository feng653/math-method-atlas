# 2019-301-18：积分递推与相邻比值

(I) 证明单调性和积分递推式；(II) 求相邻积分比值。分部积分属于前置步骤，本章只归档第 (II) 问的夹逼。

沿用记录中的正性、递减性与关系：

$$
\frac{n-1}{n+2}=\frac{a_n}{a_{n-2}}
\le\frac{a_n}{a_{n-1}}\le1.
$$

两端趋于 1。记录采用 HTML 中的 $n+2$ 分母，并指出另一转载中的 $n-2$ 为错误；本页未重新查验该版本差异。
