# 2014-301-10：周期与奇性取值

先由局部积分恢复函数，奇性给出 $f(0)=0$，并得到 $f(1)=-1$；周期为 4，可把 $f(7)$ 归到 $f(-1)$，再用奇性取值。局部积分是前置步骤，本章归类只针对周期与反射归约，不能将局部二次表达式延伸到全实轴。
