# 2016-301-04：阶梯函数差商

右侧阶梯函数的差商被 $1$ 与 $(n+1)/n$ 夹住，左侧差商也是 1。本章只归入“夹逼确定差商极限”；最终是否可导还要结合导数定义，不能把这个入口称为整题求导工具。

学习入口：[用有界性或上下界确定极限](../problem-types/bounded-squeeze/index.md)。
