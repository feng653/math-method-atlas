# 2012 年数学一第 3 题

连续性前提下辨析可微与二重极限的逻辑关系。

从[辨析连续、偏导存在与可微](../problem-types/differentiability/index.md)进入解题。

## 已有条件摘要

已知二元函数在原点连续。以下四个推断中，哪一个由给定条件必然成立？

$$
\begin{aligned}
L_1&=\lim_{(x,y)\to(0,0)}\frac{f(x,y)}{|x|+|y|},\\
L_2&=\lim_{(x,y)\to(0,0)}\frac{f(x,y)}{x^2+y^2}.
\end{aligned}
$$


- A：$L_1$ 为有限实数 $\Rightarrow$ 原点可微。
- B：$L_2$ 为有限实数 $\Rightarrow$ 原点可微。
- C：原点可微 $\Rightarrow L_1$ 存在。
- D：原点可微 $\Rightarrow L_2$ 存在。
