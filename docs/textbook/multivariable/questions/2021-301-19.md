# 2021 年数学一第 19 题

空间交线到坐标面的最大距离。

从[求等式约束下的极值与最值](../problem-types/constrained-extrema/index.md)进入解题。

## 已有条件摘要

曲线 C 由下面两个曲面的交线给出。

$$
C:\begin{cases}x^2+2y^2-z=6,\\4x+2y+z=30.\end{cases}
$$


- 求 C 上的点到 xOy 坐标面的距离的最大值。

本题问交线上到平面的距离，不是交线的切线。目标应先写成 $|z|$；消元得到完整可行集后再比较两端。
