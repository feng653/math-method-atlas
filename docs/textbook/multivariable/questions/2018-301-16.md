# 2018 年数学一第 16 题

固定总周长下三个平面图形的面积和最小值。

从[求等式约束下的极值与最值](../problem-types/constrained-extrema/index.md)进入解题。

## 已有条件摘要

一根长 2 米的铁丝分成三段，分别围成圆、正方形和正三角形。


- 判断这三个图形的面积总和是否有最小值；若有，求最小值。
