# 2017 年数学一第 3 题

沿非单位向量指定方向计算方向导数。

从[求给定方向的方向导数](../problem-types/directional-derivative/index.md)进入解题。

## 已有条件摘要

给定光滑三元函数、考察点及一个非单位方向向量。

$$
f(x,y,z)=x^2y+z^2,\quad P=(1,2,0),\quad n=(1,2,2)
$$

- A：$12$
- B：$6$
- C：$4$
- D：$2$

- 求P处沿n方向的方向导数。
