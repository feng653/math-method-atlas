# 2013 年数学一第 2 题

隐式曲面在指定点的切平面。

从[求切平面、法线及切点条件](../problem-types/surface-tangent/index.md)进入解题。

## 已有条件摘要

求下列隐式曲面在指定点的切平面。

$$
x^2+\cos(xy)+yz+x=0,\qquad P=(0,1,-1)
$$

- A：$x-y+z=-2$
- B：$x+y+z=0$
- C：$x-2y+z=-3$
- D：$x-y-z=0$

- 写出切平面方程，并与选项对应。
