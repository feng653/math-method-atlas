# 求一点处的偏导数与全微分

稳定题型 ID：`multivariable-point-differential`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

先分清需要轴向导数还是存在全方向线性近似，再在目标点求系数。

## 识别信号

- 题目只求某一点的偏导或全微分；函数可能由沿曲线的已知关系给出。

## 解题流程

1. 分段点的偏导使用增量商，不直接套邻域表达式。
2. 若只给沿曲线的函数值，可微前提下对曲线参数求导，组成关于点上偏导的线性方程组。
3. 确认可微后写全微分；隐式关系可先在目标点确定函数值再微分。

## 方法选择

- `hm-partial-total-differential`：用偏导定义或可微线性主部确定点上微分。
- `hm-multivariable-chain`：沿两条已知曲线求导，若切向量独立可解出两个偏导。
- `hm-multivariable-implicit`：点上函数值隐式给定时，检查非零Jacobian后微分。

## 关键公式与条件

### 点上全微分

$$
df|_{(a,b)}=f_x(a,b)\,dx+f_y(a,b)\,dy
$$

- 条件：f在(a,b)可微；dx和dy为独立增量。

可微函数的一阶线性主部定义为全微分，其系数由两个轴向增量商唯一确定。

## 易混边界

- 仅有两个偏导数不能宣称全微分存在。
- 两条曲线切向量共线时，得到的方程组可能无法唯一确定两个偏导。
