# 求具体表达式的偏导数与全微分

稳定题型 ID：`multivariable-explicit-differentiation`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

固定其余自变量逐次求导，遇到变上限积分先处理对上限的依赖。

## 识别信号

- 函数由初等表达式或含参变上限积分明确给出；求一阶、混合偏导或全微分。

## 解题流程

1. 标明每次求导时保持不变的自变量。
2. 整理表达式；变上限积分可先选择只影响上限的变量求导，减少含参积分求导的复杂度。
3. 二阶导数保留系数与内层变量的全部变化，最后代点。

## 方法选择

- `hm-partial-total-differential`：对明确表达式逐变量求偏导，并在可微区域组合全微分。
- `hm-multivariable-chain`：表达式含复合结构时，逐层乘内函数偏导。
- `hm-newton-leibniz`：积分上限依赖变量且被积函数满足连续性条件，先将上限求导。

## 关键公式与条件

### 含参变上限积分的求导顺序

$$
F(x,y)=\int_0^{xy}e^{xt^2}\,dt,\qquad F_y=x e^{x^3y^2}
$$

- 条件：该表达式为2020年第12题；被积函数光滑，固定x对y求导。

y只通过上限xy进入积分，因此先用上限导数乘上限处的被积函数，再对x求导。
