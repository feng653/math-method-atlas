# 求最大方向导数或反求参数

固定点处，可微函数的最大方向导数等于梯度范数；若取点也变化，再对范数作约束最值。分清“点固定、方向变化”和“点与方向都变化”，第二层不能漏。

可选工具：[用梯度范数求最大方向导数](../../methods/gradient-norm-optimization.md)、[用约束代入消元](../../methods/constraint-elimination.md)、[用对称变量换元降维](../../methods/symmetric-variables.md)、[用拉格朗日方程找约束候选](../../methods/lagrange-candidates.md)。
