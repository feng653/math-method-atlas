# 求抽象复合函数的一阶与高阶导数

稳定题型 ID：`multivariable-differentiation`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

画出变量依赖路径，外函数偏导保留符号，逐次求导。

## 识别信号

- f没有具体表达式，但给出f的光滑性及内函数。
- 可给沿曲线的复合关系，也可给偏微分关系反求单变量函数。

## 解题流程

1. 列出外变量、内变量与独立变量，并标明求值点在内变量空间的像。
2. 一阶导数按每条依赖路径相乘再相加。
3. 二阶求导时外函数偏导仍是复合函数，连同前面的系数一起求导。
4. 全部求导后代点；若利用内函数极值，先由可导内点极值推出其导数为零。

## 方法选择

- `hm-multivariable-chain`：抽象外函数及内函数满足相应阶数可微条件。
- `hm-partial-total-differential`：已知曲线关系求点上全微分，先解出偏导系数。

## 关键公式与条件

### 一条参数曲线上的二阶导数

$$
\frac{d^2f(u(x),v(x))}{dx^2}=f_{uu}(u')^2+2f_{uv}u'v'+f_{vv}(v')^2+f_u u''+f_v v''
$$

- 条件：f与内函数在所考察邻域C²；各偏导在(u(x),v(x))处取值。

对f_u u′+f_v v′再求一次导数，分别用链式与乘积法则；混合偏导连续时可合并为2倍。
