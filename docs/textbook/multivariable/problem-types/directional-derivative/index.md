# 求给定方向的方向导数

已知可微，先将方向单位化，再取梯度点积。分段点没有可微依据时，把射线代入差商定义；仅有坐标偏导存在不够。

可选工具：[沿射线差商求方向导数](../../methods/directional-definition.md)、[梯度与单位方向点积](../../methods/gradient-dot-product.md)。
