# 求等式约束下的极值与最值

能消元或完整参数化时先降维；否则用乘子方程找正则候选点。另查奇异点、端点及附加边界，再证明候选值是所求局部或全局结果。距离题先保留绝对值，不能默认坐标为正。

可选工具：[用约束代入消元](../../methods/constraint-elimination.md)、[用对称变量换元降维](../../methods/symmetric-variables.md)、[参数化完整约束集](../../methods/constraint-parametrization.md)、[用拉格朗日方程找约束候选](../../methods/lagrange-candidates.md)、[用加权柯西不等式求全局最值](../../methods/global-inequality.md)。
