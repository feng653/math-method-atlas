# 用可微展开求极限

题目已经给出可微性时，先写出“线性主部＋高阶余项”。把待求式中的线性项消去，观察剩下的余项是否恰好除以点到基点的距离。

可选工具：[从一阶增量提取微分](../../methods/first-order-increments.md)、[余项判别可微](../../methods/differentiability-remainder.md)。前者使用已知可微展开；后者还说明反过来如何验证可微。
