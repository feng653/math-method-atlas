# 由点上条件求全微分

目标是确定线性主部的系数。已知可微时，可对经过同一基点的复合恒等式求导，联立求两个偏导；隐式关系则先确认局部函数及可微依据，再提取一阶项。

可选工具：[沿两条曲线求导联立偏导](../../methods/curve-identities.md)、[对隐式恒等式求一阶导数](../../methods/implicit-first-order.md)、[从一阶增量提取微分](../../methods/first-order-increments.md)。
