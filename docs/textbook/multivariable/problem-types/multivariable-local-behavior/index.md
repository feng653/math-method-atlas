# 判别二重极限、连续、偏导与可微

稳定题型 ID：`multivariable-local-behavior`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

按定义域、点值、轴向增量和全方向余量逐层判断性质。

## 识别信号

- 分段定义、原点附近的分式，或由极限条件推断连续与可微。
- 题中“偏导存在”和“可微”是不同条件，不能互相替代。

## 解题流程

1. 先检查点是否属于定义域，明确趋近路径必须留在定义域内。
2. 否定极限用两条合法路径；证明存在须给关于距离的统一估计。
3. 分别代入函数值核对连续，固定另一变量求偏导，再检查线性余量除以距离的极限。

## 方法选择

- `hm-multivariable-limit`：处理二重极限、连续性；用统一估计证明，用路径差异否定。
- `hm-partial-total-differential`：在偏导已算出后，用可微定义检查线性余量。

## 关键公式与条件

### 可微的统一余量条件

$$
\lim_{(h,k)\to(0,0)}\frac{f(a+h,b+k)-f(a,b)-f_x(a,b)h-f_y(a,b)k}{\sqrt{h^2+k^2}}=0
$$

- 条件：目标点是内点，两偏导存在。

将可微定义中的线性主部移到分子；分母是增量长度，要求整个邻域统一趋零。
