# 求最大最小值与约束优化

稳定题型 ID：`multivariable-global-optimization`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

先判断最值是否存在，再穷尽内部、边界和奇异候选并比较。

## 识别信号

- 目标含“最大值、最小值”，或有闭域、曲线、几何资源约束。

## 解题流程

1. 把题目转成明确目标函数及可行域；距离要考虑绝对值，长度要保留正性。
2. 连续函数在非空紧集上有最大最小值；非紧集或开集另查无穷远和边界极限。
3. 内部求驻点；正则等式约束用乘子法；各段边界降维，并加入角点、非正则点。
4. 逐一比较候选值，回到原变量验证可行性及是否能取到。

## 方法选择

- `hm-lagrange-multipliers`：约束梯度独立时列乘子方程；闭域同时处理各边界。
- `hm-hessian-extrema`：求闭域内部驻点或判断二次目标的严格凸性。

## 关键公式与条件

### 等式约束驻点方程

$$
\nabla f=\lambda\nabla g,\qquad g=0
$$

- 条件：f和g在局部C¹；可行极值点满足∇g≠0。

正则约束的切向增量与∇g正交；极值点沿任一切向的一阶变化为零，故∇f与∇g平行。
