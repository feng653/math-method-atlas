# 求二元极限

先看研究点是否为表达式的连续点；能代入便直接代入。出现不定式时，尝试把误差压在只依赖距离的量下面。式子含有 $x^2+y^2$ 时，极坐标常能整理量级，但必须对所有角度统一估计。

可选工具：[连续性代入](../../methods/continuity-substitution.md)、[夹逼估计](../../methods/squeeze-estimate.md)、[极坐标一致估计](../../methods/polar-uniform-estimate.md)。
