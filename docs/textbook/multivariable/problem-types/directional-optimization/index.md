# 求方向导数与最大变化率

稳定题型 ID：`directional-optimization`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

先归一化方向，再区分固定点与移动点的优化。

## 识别信号

- 求梯度、给定单位方向的方向导数、固定点的最大方向导数，或带取点约束的最大变化率。

## 解题流程

1. 将方向向量归一化。
2. 固定点用梯度点积；若点也变化，将梯度模作为新目标再处理点约束。

## 方法选择

- `hm-direction-gradient`：函数可微，求给定方向变化率或该点最大变化率。
- `hm-direction-cosines`：方向以坐标轴夹角给出，检查三个余弦平方和为1。
- `hm-lagrange-multipliers`：最大变化率还需在曲线面上选点时，对梯度模平方优化。

## 关键公式与条件

### 最大方向导数

$$
\max_{\|e\|=1}D_e f=\|\nabla f\|,\qquad e_{\max}=\frac{\nabla f}{\|\nabla f\|}
$$

- 条件：f在目标点可微；最优方向公式另要求梯度非零。

由Cauchy不等式梯度点积不超过其模，方向与梯度同向时等号成立；梯度为0时所有单位方向均给0。
