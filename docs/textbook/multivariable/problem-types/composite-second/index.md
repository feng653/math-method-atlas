# 求复合函数二阶及混合导数

从一阶导数继续求导，每一项都同时考虑外层偏导与内层系数的变化。交换混合次序前核对换序条件，常用充分条件是二阶偏导连续；指定点代入应放在相关求导完成之后。

可选工具：[再次链式求导](../../methods/second-order-chain.md)、[核对条件后交换混合次序](../../methods/mixed-partials-interchange.md)。
