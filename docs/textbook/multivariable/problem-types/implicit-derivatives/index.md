# 求隐函数或隐函数组的导数

先确定谁是自变量、谁是隐变量。单方程求导后解出目标偏导；方程组则把未知偏导作为未知数联立。二阶求导时，第一次得到的隐导数也要继续求导。

可选工具：[对隐式恒等式求一阶导数](../../methods/implicit-first-order.md)、[对隐式一阶关系再求导](../../methods/implicit-second-order.md)、[联立隐函数组的导数方程](../../methods/implicit-linear-system.md)。
