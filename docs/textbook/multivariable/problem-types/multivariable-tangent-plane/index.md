# 求曲面切平面、法线与切点约束

稳定题型 ID：`multivariable-tangent-plane`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

把曲面的局部线性近似转为平面方程，再使用过点或垂直关系求未知切点。

## 识别信号

- 已知曲面与切点，或切平面过给定点、与指定平面垂直，要求切面、法线或切点轨迹。

## 解题流程

1. 隐式曲面取非零梯度作法向量；显式z=f(x,y)可取(fx,fy,−1)。
2. 写过切点的点法式；法线用参数式，避免零分量引起除零。
3. 未知切点必须同时满足原曲面方程和附加几何条件。
4. 综合题由切平面确定投影域后，再交给闭域最值或积分方法。

## 方法选择

- `hm-tangent-plane`：正则曲面点求切面法线，或通过几何条件反求切点。
- `hm-multivariable-implicit`：隐式曲面局部可表示为函数时，用隐式偏导核对法向量。

## 关键公式与条件

### 正则隐式曲面的切平面与法线

$$
\nabla F(P)\cdot(X-P)=0,\qquad X=P+t\nabla F(P)
$$

- 条件：F在P邻域C¹，F(P)=0且∇F(P)≠0。

曲面内任一可微曲线满足F恒为零；链式法则使切向量与∇F正交。第一式为切平面，第二式为法线。

## 易混边界

- ∇F=0时不能套标准切面公式；需独立分析曲面的局部几何。
- 切平面通常并不包含曲面上的其他给定点，除非题目明确提出此约束。
