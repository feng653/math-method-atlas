# 求切平面、法线及切点条件

先从曲面的一阶信息得到法向量。切点未知时，把切点作为未知数写平面，再代入过点、平行或垂直条件；得到切点后必须回查它确实在原曲面上。

可选工具：[用全微分写显式曲面的切平面](../../methods/graph-tangent.md)、[用梯度写隐式曲面的切平面](../../methods/implicit-surface-tangent.md)、[设未知切点再代入几何条件](../../methods/unknown-contact-point.md)。
