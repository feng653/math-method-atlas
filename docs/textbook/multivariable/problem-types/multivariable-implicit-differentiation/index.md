# 求隐函数及隐方程组的偏导与微分

稳定题型 ID：`multivariable-implicit-differentiation`。本页是现有题型卡的编辑底稿，卡片唯一数据仍在 `content/libraries/math-one/problem-types/`。

先验证局部可解条件，再将求导结果视为待求导数的线性方程。

## 识别信号

- 未知函数只通过F(x,y,z)=0或方程组出现。

## 解题流程

1. 先代入目标自变量确定对应的未知函数值。
2. 单方程检查Fz非零；方程组检查对未知量的Jacobian行列式非零。
3. 固定另一自变量求导，或整体微分；解出偏导或微分。
4. 高阶导数继续对原恒等式求导，不能把上一阶中的z当作常数。

## 方法选择

- `hm-multivariable-implicit`：隐函数存在条件成立后，求一阶、高阶偏导或方程组微分。
- `hm-partial-total-differential`：将得到的偏导组合成全微分。

## 关键公式与条件

### 隐式全微分

$$
dz=-\frac{F_x}{F_z}\,dx-\frac{F_y}{F_z}\,dy
$$

- 条件：F在点的邻域C¹，点满足F=0且Fz非零。

隐函数定理保证局部可微；对恒等式微分后解Fz dz=−Fx dx−Fy dy。
