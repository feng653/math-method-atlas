# 方法作者交接：每篇解决一个可执行动作

题型篇经主 agent 复核后共 21 个任务入口，39 道原有真题全部有题目文件和至少一个入口。下面 41 项是写作建议，不是网站方法 ID 或已核验频次。每项一篇 methods/<slug>.md；可基于实际重合调整，但先说明理由。不要把“求极限”“可微性”“几何应用”写成混装多个工具的大节点。

每篇自然交代选用时机、所需条件、关键操作，并给 1—2 道完整例题。标题可简短，段落与公式随推理分行，不机械填满固定栏目。真题表达式来源不足时用明确标注的自编例题；不能为了真题数量牺牲精确性。

## 重点审校交接

以下是真题来源资料与主 agent 本轮重读提供的边界。方法作者仍须独立演算；不要复制来源解析。

- **2015 年第 17 题：** f=x+y+xy，约束 x²+y²+xy=3，点与单位方向都变化。主 agent 得到 s=x+y∈[-2,2]，梯度范数平方为 9-(s-1)²。方法篇须解释可行区间及取等点，不能只做固定点方向优化。
- **2021 年第 19 题：** 先写距离 |z|。主 agent 消元得到 (x+2)²+2(y+1/2)²=81/2，进而 z∈[12,66]；最大距离在 (-8,-2,66) 取到。须独立重算这一范围，不能在论证前去掉绝对值。此题不归空间曲线切线题。
- **2016 年第 11 题：** 外函数只给可微，不能当作 C¹。由式子求点值后，应说明所用局部连续分支及其可微依据，再作一阶增量或链式处理；避免以隐函数定理分母非零掩盖其余前提。若不准备展开这一微妙论证，可只把它保留为题目索引，方法示例改用条件完整的自编题。
- **2020 年第 12 题：** 主 agent 已在 sources/recheck.md 写明被积函数、上限与指定混合次序。按该顺序消去积分即可，无须附加未经证实的换序故事。
- **2020 年第 15 题：** Taylor 与 Hessian 都可独立处理，但不能说原卷要求 Taylor，也不能把新增细分文章视为正式 verified 关联。
- **2011 年第 11 题：** 已有资料警告第三方上限可能漏字；若使用必须优先重看原 PDF。
