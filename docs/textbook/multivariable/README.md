# 多元函数微分学

先分清概念，再判断题目要求，最后选择能完成当前步骤的工具。

- [概念与基本结论](concepts.md)：本章新概念的定义、常用性质和定理条件。
- [按题型找方法](problem-types/README.md)：从求极限、判可微、求偏导、求极值等任务进入。
- [方法工具箱](methods/README.md)：每种方法独立成篇，配完整演算。
- [真题索引](questions/README.md)：39 道数学一题目的摘要、条件和来源。

例如，遇到“求二元极限”，可以分别尝试[连续性代入](methods/continuity-substitution.md)、[夹逼估计](methods/squeeze-estimate.md)或[极坐标一致估计](methods/polar-uniform-estimate.md)；若要否定极限存在，则选[不同路径反证](methods/two-paths.md)。这些工具各自完成不同的证明动作。

遇到“原点是否可微”，先用[必要条件](methods/necessary-condition-rejection.md)排除；能验证偏导连续时用[充分条件](methods/continuous-partials.md)，否则回到[线性余项判别](methods/differentiability-remainder.md)。
