# 二元函数曲面、极限与连续性

既有方法 ID：`hm-multivariable-limit`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

用路径否定极限，用对所有方向统一有效的估计证明极限，并将距离阶数转为可微余项。

## 直觉与选择依据

单条路径是一名证人：能证明不同，却不能代表所有趋近方式。径向上界同时控制整片邻域。

寻找路径适合反证；寻找统一不等式适合证明。分母含x⁴+y²时，令y=x²能让两项同阶，比只试y=kx更有效。

可微是某个线性函数能留下o(r)误差。若已知f(0)=0并有f=O(r²)，线性主部可直接取零。

## 符号

- **r**：点到目标点的欧氏距离；用于统一衡量所有方向上的小量。
- **O(r²)**：存在固定M使邻近点处绝对值不超过Mr²。
- **o(r)**：函数除r趋于零，比一阶距离更小。

## 适用条件与边界

- 极限在定义域聚点讨论，路径上的点必须属于定义域并避开极限点。
- 代数连续法要求表达式在点附近合法且分母极限非零；夹逼上界必须对全部邻近点成立。
- 判可微时在内点检验减去线性主部后的余项，不能只验证若干直线。

## 可执行步骤

1. 先写定义域与目标点，用平移把目标点移到原点，记r为到原点的距离。
2. 先查直接代入；出现不定式时比较分子分母阶数，并试坐标轴、直线、与分母平衡的曲线路径。
3. 若两条合法路径极限不同，立即判不存在；若相同，继续寻找不依赖方向的上界。
4. 要证明可微，先确定函数值与候选偏导，再把余项绝对值除r，证明其趋零。

## 核心公式

$$r=\sqrt{x^2+y^2},\quad r\le |x|+|y|\le\sqrt2r,\quad |f(x,y)-L|\le\phi(r)\to0$$

## 易错点

- 沿任意固定直线相同仍不能证明二重极限存在。
- 极坐标固定角度只检验射线，必须给与角度无关的估计。
- O(r)只给存在C使绝对值≤Cr的上界，不给同阶下界，也不推出o(r)；O(r²)则必为o(r)。
- 函数值未给零时，不可直接把f/r称作可微余项。

## 真题原创讲解：2012-301-03

[题目条件、来源与题型归属](../questions/2012-301-03.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

已知f在原点连续，记f/(|x|+|y|)、f/(x²+y²)在原点的极限为L₁、L₂。判断哪个命题必成立：A，L₁有限推出可微；B，L₂有限推出可微；C，可微推出L₁存在；D，可微推出L₂存在。这里存在均指有限实数极限。

$$L_1=\lim\frac{f(x,y)}{|x|+|y|},\qquad L_2=\lim\frac{f(x,y)}{x^2+y^2}$$

### 证明B：L₂有限推出可微

有限极限使比值在去心邻域有界。于是f趋零，结合连续性知原点函数值为零；取零线性主部，余项除r趋零，故可微且两个偏导均零。

$$|f(x,y)|\le Mr^2,\quad f(0,0)=0,\quad \frac{|f(x,y)|}{r}\le Mr\to0$$

### 否定A：一阶有界不够

取f=|x|+|y|，原点连续且L₁=1，但x轴差商为|t|/t，两侧不一致，所以偏导不存在，更不可微。

$$f(x,y)=|x|+|y|,\quad \frac{f(t,0)-f(0,0)}{t}=\frac{|t|}{t}$$

### 否定C和D：可微不强迫这两个比值收敛

取处处可微的f=x。沿y=0且x分别由正负侧趋零，第一个比值分别为1和−1；第二个比值是1/x，没有有限极限。故仅B必然成立。

$$f(x,y)=x,\quad \frac{x}{|x|}=\begin{cases}1&x>0\\-1&x<0\end{cases},\quad \frac{x}{x^2}=\frac1x$$

## 补充推导与教学边界

自编补充：$f=x^2y/(x^4+y^2)$ 沿所有过原点直线趋零，却沿 $y=x^2$ 恒为 $1/2$；沿直线的检验不完整。正向证明示例：$|xy|/\sqrt{x^2+y^2}\le r/2\to0$，这里不等式来自 $2|xy|\le x^2+y^2$。
