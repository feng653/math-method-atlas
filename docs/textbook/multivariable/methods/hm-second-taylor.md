# 二元函数二阶泰勒展开

既有方法 ID：`hm-second-taylor`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

在指定点把函数分成常数、线性项、二次型与高阶余项，用可控误差解释局部近似和极值。

## 直觉与选择依据

先用平面捕捉斜率，再用二次曲面捕捉弯曲；余项说明这张局部模型有多准确。

把多元函数限制到线段φ(t)=f(a+th,b+tk)，一元泰勒公式给出梯度线性项与Hessian二次项；二阶偏导连续保证余项统一为o(r²)。

判极小不能只说“二次项正”。要得到至少cr²的正下界，才能确保高阶余项不会翻转符号。

## 符号

- **h、k**：相对于展开点的坐标增量。
- **o(h²+k²)**：误差除以距离平方趋零，统一适用于各种方向。
- **二次型**：形如Ah²+2Bhk+Ck²的二次齐次多项式。

## 适用条件与边界

- 本卡采用函数在展开点邻域C²的充分条件，得到二阶Peano余项o(r²)。
- 所有偏导系数均在同一展开点求值；增量h、k相对于该点。
- 驻点处线性项消失，非驻点不可忽略线性项。
- 二次型退化时展开仍有效，但二阶项可能不足以判断符号；有限阶截断不是一般函数恒等式。

## 可执行步骤

1. 固定展开点(a,b)，置h=x−a、k=y−b并记r²=h²+k²。
2. 依次计算函数值、一阶偏导和二阶偏导在(a,b)处的值。
3. 按常数、线性、二次项排列，混合项写成(1/2)·2f_xy hk。
4. 标明余项o(r²)；多项式可直接展开得到精确余项并核对其阶数。
5. 用于极值时给二次型统一界并证明余项更小；半正定或全零时继续展开或另找路径。

## 核心公式

$$f(a+h,b+k)=f(a,b)+f_xh+f_yk+\frac12(f_{xx}h^2+2f_{xy}hk+f_{yy}k^2)+o(h^2+k^2)$$

## 易错点

- f_xy hk的实际系数为f_xy，不应忘记外层1/2或内层2。
- 展开点不在原点时，不能把x、y误作增量。
- 点上二阶偏导存在本身不足以保证本卡采用的完整泰勒结论。
- 沿每个固定方向余项很小，不代替对全部邻近增量的o(r²)控制。

## 真题原创讲解：2020-301-15

[题目条件、来源与题型归属](../questions/2020-301-15.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

对f=x³+8y³−xy，使用二阶展开判断两个驻点的性质。这是本题的原创替代论证，原题没有指定使用Taylor。

$$f_x=3x^2-y,\quad f_y=24y^2-x,\quad \text{驻点：}(0,0),(1/6,1/12)$$

### 在第二驻点精确展开

置x=1/6+h、y=1/12+k。常数项为−1/216，一次项因驻点条件抵消，直接展开得到精确三次余项。

$$f(1/6+h,1/12+k)=-\frac1{216}+\frac12(h^2-2hk+4k^2)+h^3+8k^3$$

### 给统一二次下界并控制余项

利用2|hk|≤h²/2+2k²，二次项至少为r²/4；三次项绝对值不超过9r³。取0<r<1/36，增量严格为正，故该点严格极小。

$$\frac12(h^2-2hk+4k^2)\ge\frac14(h^2+k^2),\quad |h^3+8k^3|\le9r^3,\quad \Delta f\ge r^2(1/4-9r)>0$$

### 在原点寻找两种符号

原点展开就是原多项式；二阶主项−hk不定。取k=h=t和k=−h=−t，足够小的非零t分别给负值与正值，原点是鞍点。

$$f(t,t)=9t^3-t^2=t^2(9t-1)<0\ (0<|t|<1/9),\quad f(t,-t)=-7t^3+t^2=t^2(1-7t)>0\ (0<|t|<1/7)$$

## 补充推导与教学边界

自编近似例：$e^{x+y}=1+x+y+\frac12x^2+xy+\frac12y^2+o(x^2+y^2)$。因为 $|x+y|\le\sqrt2r$，一元指数展开的三阶误差在原点邻域为 $O(r^3)=o(r^2)$。用于退化极值时请同时阅读 [Hessian方法](hm-hessian-extrema.md) 中沿弯曲路径变号的例子。
