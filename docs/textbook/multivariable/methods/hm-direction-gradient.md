# 方向导数与梯度

既有方法 ID：`hm-direction-gradient`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

先将方向向量单位化，再用梯度点积求每单位距离的变化率；方向或取点优化须分别处理。

## 直觉与选择依据

梯度是一支指向最快上升方向的箭头；沿其他单位方向的变化率就是它在该方向的投影。

把增量h=te代入可微展开，除以t并令t趋零得到点积公式；可微保证余项除t趋零。

柯西不等式给∇f·e≤‖∇f‖；非零梯度时，同方向且单位长度正好取等号。

## 符号

- **∇f(P)**：目标点各偏导构成的向量，依赖点P。
- **e**：长度为1的有向向量。
- **D_e f**：沿e每移动单位距离时的一阶变化率，可以为负。

## 适用条件与边界

- 梯度点积公式要求函数在目标点可微，偏导存在或方向导数存在本身不够。
- 方向向量必须非零并先单位化；这里方向导数按每单位距离定义。
- 最大方向导数结论是在固定点、全部单位方向中优化；点也变化时还要在可行点集上优化梯度模。
- 梯度为零时各方向导数都为零，没有唯一最快上升方向。

## 可执行步骤

1. 写目标点P和有向方向向量v；由两点给方向时按终点减起点。
2. 确认可微，先求各偏导再代P组成梯度。
3. 计算长度‖v‖，取e=v/‖v‖，算∇f(P)·e。
4. 若求固定点最大变化率，用‖∇f(P)‖，非零时方向为梯度单位向量。
5. 若目标点受约束且可选，再把梯度模或模平方作为新目标函数求最值，并回代具体方向。

## 核心公式

$$D_e f(P)=\nabla f(P)\cdot e,\quad e=\frac{v}{\|v\|},\quad \max_{\|e\|=1}D_e f(P)=\|\nabla f(P)\|$$

## 易错点

- 直接点乘未单位化向量得到每单位参数变化率，通常不是题目所求方向导数。
- 方向反向使导数变号。
- 梯度模给最大有向导数；最小为负的梯度模。
- 取点也可变化时，固定点的柯西不等式还没有完成整道优化题。

## 真题原创讲解：2017-301-03

[题目条件、来源与题型归属](../questions/2017-301-03.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

求f(x,y,z)=x²y+z²在P=(1,2,0)处沿向量(1,2,2)的方向导数。

$$f=x^2y+z^2,\quad P=(1,2,0),\quad v=(1,2,2)$$

### 求梯度并代点

多项式处处可微，满足点积公式前提。分别固定其他变量求导。

$$\nabla f=(2xy,x^2,2z),\qquad \nabla f(P)=(4,1,0)$$

### 把方向换成单位向量

向量长度为3，不可直接用原向量点乘。

$$\|v\|=\sqrt{1+4+4}=3,\qquad e=(1/3,2/3,2/3)$$

### 计算投影并复核量级

点积为2。梯度模为√17，所得值的绝对值没有超过它，符合方向导数的范围。

$$D_e f(P)=4\cdot\frac13+1\cdot\frac23+0\cdot\frac23=2,\quad |2|\le\sqrt{17}$$

## 补充推导与教学边界

自编复核：沿单位方向取 $P+te=(1+t/3,2+2t/3,2t/3)$，代入原函数，展开一次项为 $2t$，故差商极限为2。若沿原向量取 $P+tv$，一次项为 $6t$；此时参数每增加1，距离增加3，结果6对应参数速率。另见 [2015年17题](../questions/2015-301-17.md) 的取点与方向共同优化任务；具体条件以该题记录为准，不由摘要补造数值。
