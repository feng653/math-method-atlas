# 偏导数与全微分判别

既有方法 ID：`hm-partial-total-differential`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

由差商确定偏导，由统一的一阶余项检验可微；把全微分用于近似、比例极限和切向关系。

## 直觉与选择依据

全微分把曲面局部替换成切平面；原曲面离开这个平面的法向偏差，比水平距离更小。

沿h=(t,0)和h=(0,t)代入可微定义，唯一的线性系数必是两个偏导；因此先求偏导只是确定候选模型，并未证明模型有效。

若f(0)=0且n=(A,B,−1)，则n·(x,y,f)=Ax+By−f恰为余项的相反数。这是识别几何比例极限的关键。

## 符号

- **A、B**：目标点的两个偏导值，是线性模型的系数。
- **R**：真实增量减去线性模型后的误差。
- **n、v**：例题中n是固定法向量，v是随(x,y)变化的曲面位置向量。

## 适用条件与边界

- 经典偏导与可微在定义域内点讨论。
- 各偏导在邻域存在且在目标点连续是可微的充分条件；仅偏导存在不能直接写可微展开。
- 题目已给可微时可直接使用线性展开；分段拼接点先按差商定义处理。

## 可执行步骤

1. 确定目标点、函数值和独立变量；在特殊点用两条坐标差商求候选偏导A、B。
2. 常规光滑表达式可由偏导连续判可微；否则写R=f(a+h)−f(a)−Ah₁−Bh₂。
3. 用所有方向统一的估计证明R/r趋零；若找到一条路径不趋零，则不可微。
4. 可微确认后写df=A dx+B dy；处理比例极限先识别并消去这个线性主部。

## 核心公式

$$f(a+h)-f(a)=Ah_1+Bh_2+o(\|h\|),\quad df=A\,dx+B\,dy,\quad A=f_x(a),\ B=f_y(a)$$

## 易错点

- 连续且偏导存在仍可能不可微。
- 全微分是线性近似，不能写有限增量恒等于df。
- 偏导是在一条坐标轴方向上的数；可微要求全方向统一误差。
- 向量与法向正交只消除法向的一阶投影，不会使所有点积、叉积都成为高阶小量。

## 真题原创讲解：2020-301-03

[题目条件、来源与题型归属](../questions/2020-301-03.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

f在原点可微且f(0,0)=0。设n=(fx(0),fy(0),−1)，d为与n正交的非零向量，v=(x,y,f(x,y))。判断|n·v|、‖n×v‖、|d·v|、‖d×v‖除r所得极限中哪一个必为零。

$$r=\sqrt{x^2+y^2},\quad n\cdot d=0,\quad d\ne0$$

### 写可微展开

记A、B为原点偏导。题目已给可微，可直接使用余项展开，无须额外假设偏导连续。

$$f(x,y)=Ax+By+R(x,y),\qquad R/r\to0$$

### 认出被消去的线性部分

n与v点乘后，Ax+By完全抵消，只剩−R。取绝对值不改变趋零结论，故A选项必成立。

$$n\cdot v=Ax+By-f(x,y)=-R,\qquad \frac{|n\cdot v|}{r}\to0$$

### 逐项反驳其余必然性

取合法函数f=0和d=(1,0,0)，于是n=(0,0,−1)、v=(x,y,0)。B的比值恒1；C沿y=0时为1而沿x=0时为0；D沿x=0时为1而沿y=0时为0，均不保证趋零。

$$\frac{\|n\times v\|}{r}=1,\quad \frac{|d\cdot v|}{r}=\frac{|x|}{r},\quad \frac{\|d\times v\|}{r}=\frac{|y|}{r}$$

## 补充推导与教学边界

自编判别练习：令 $f=xy/\sqrt{x^2+y^2}$，原点补零。两个坐标差商均为零且 $|f|\le r/2$ 保证连续；但沿 $x=y=t>0$，$f/r=1/2$，故不可微。这个例子说明必须检验余项，不能把“偏导存在”和“连续”拼成错误充分条件。
