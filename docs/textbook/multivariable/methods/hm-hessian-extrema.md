# 二元函数无约束极值

既有方法 ID：`hm-hessian-extrema`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

先求全部内点驻点，再用Hessian判断二次变化；退化时回到函数增量，不能把D=0当作无极值。

## 直觉与选择依据

驻点的一阶倾斜已经消失；二阶弯曲决定附近是碗、倒碗还是马鞍。弯曲退化时要继续看真实增量。

由二阶泰勒式，驻点附近增量为二次型的一半加o(r²)。正定二次型有统一正下界cr²，故能压过余项。

D<0的二次型沿两个方向符号不同，沿足够短的对应直线仍一正一负。D=0恰好失去严格二阶控制，必须换工具。

## 符号

- **Hessian**：由二阶偏导构成的对称矩阵，控制驻点附近二次项。
- **D=AC−B²**：二元Hessian行列式；它与A一起判断二次型符号。
- **鞍点**：驻点附近任意小邻域内都有函数值更大和更小的点。

## 适用条件与边界

- 驻点必要条件适用于内点局部极值且一阶偏导存在；不可微点和边界另查。
- 二阶判别采用函数在驻点邻域C²的充分正则条件。
- D=0时二阶判据无结论，需更高阶展开、配方、不等式或变号路径。
- 局部极值判别不等于全局最值；有约束时不可直接用无约束Hessian替代约束分析。

## 可执行步骤

1. 写定义域并解f_x=f_y=0，保留所有解及分支。
2. 在每个驻点分别计算A=f_xx、B=f_xy、C=f_yy和D=AC−B²。
3. D>0时按A正负判严格极小或极大；D<0判鞍点；D=0转入增量分析。
4. 退化时先写精确增量或最低非零齐次项：符号一致并能控制余项才可判极值；找到正负值趋近则排除极值。
5. 算出极值函数值；若要求全局最值，还要补查边界、不可微点及无穷远。

## 核心公式

$$D=AC-B^2:\quad D>0,A>0\Rightarrow\text{严格极小};\quad D>0,A<0\Rightarrow\text{严格极大};\quad D<0\Rightarrow\text{鞍点}$$

## 易错点

- 驻点只是候选点，不能解出梯度零就宣布极值。
- D中的混合偏导必须平方；B的符号不能漏。
- 半正定二次型可能沿某些方向为零，不能压过所有高阶余项。
- 只沿两条路径都为正不能证明极小；证明需覆盖整个邻域。

## 真题原创讲解：2020-301-15

[题目条件、来源与题型归属](../questions/2020-301-15.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

求f(x,y)=x³+8y³−xy的极值。

$$f=x^3+8y^3-xy$$

### 求全部驻点

第一式给y=3x²，代第二式得到x(216x³−1)=0，因此有两个实驻点。

$$f_x=3x^2-y=0,\quad f_y=24y^2-x=0,\quad (x,y)=(0,0),\ (1/6,1/12)$$

### 逐点计算Hessian

二阶导数为A=6x、B=−1、C=48y。在原点D=−1，故为鞍点，不是极值点。

$$H=\begin{pmatrix}6x&-1\\-1&48y\end{pmatrix},\quad D(0,0)=-1$$

### 判别第二个驻点并计算值

在(1/6,1/12)处A=1、B=−1、C=4，D=3>0且A>0，故严格极小。函数光滑处的内点极值必须是驻点，已穷尽驻点，所以没有局部极大值。

$$f(1/6,1/12)=\frac1{216}+\frac1{216}-\frac1{72}=-\frac1{216}$$

## 补充推导与教学边界

### 自编退化驻点：实际怎样继续

$f_1=x^4+y^4$ 与 $f_2=x^4-y^4$ 在原点的Hessian都是零。对 $f_1$，由 $(x^2-y^2)^2\ge0$ 得 $x^4+y^4\ge(x^2+y^2)^2/2>0$（非原点），故严格极小；对 $f_2$，沿 $y=0$ 为正，沿 $x=0$ 为负，故鞍点。

更容易误判的自编例：$g=(y-x^2)^2-x^6$。在原点Hessian半正定；沿 $x=0$，$g=y^2>0$，但沿弯曲路径 $y=x^2$，$g=-x^6<0$，仍是鞍点。最低二次项 $y^2$ 在x轴退化，不能独自定结论。

本真题的严格极小不是全局极小：固定 $y=0$，$f=x^3$ 在实数轴上下无界。
