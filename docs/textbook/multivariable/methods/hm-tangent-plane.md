# 曲面切平面与法线

既有方法 ID：`hm-tangent-plane`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

用曲面局部线性化得到切平面；显式图像用偏导，正则隐式曲面用梯度作法向。

## 直觉与选择依据

留在曲面上的微小移动，不应在法向方向产生一阶偏移，因此梯度垂直于所有切向移动。

若r(s)始终在F=0上，对F(r(s))求导得∇F·r′=0。因此非零梯度同时垂直于各条曲面曲线的切向量。

显式曲面可写F=f(x,y)−z，梯度为(f_x,f_y,−1)，不会为零；它与直接线性化得到的切面完全一致。

## 符号

- **P、X**：P是固定切点，X=(x,y,z)是切平面或法线上的变量点。
- **∇F(P)**：正则隐式曲面在P处的法向量。
- **t**：法线上的实参数，不是曲面函数的自变量。

## 适用条件与边界

- 显式曲面z=f(x,y)要求f在目标点可微。
- 隐式曲面F=0采用F在点附近C¹且∇F(P)≠0的正则充分条件。
- 必须先确认给定点属于曲面；梯度为零时线性方程退化，不能用零法向量。
- 求未知切点时，点在曲面与题给附加几何条件须联立，并检查全部候选点。

## 可执行步骤

1. 辨别显式或隐式表示，将隐式方程全部移到一侧。
2. 代点检查曲面方程，计算梯度或显式偏导，并确认法向量非零。
3. 以法向量n写n·(X−P)=0，展开并代P检查常数项。
4. 若求法线，写X=P+tn；若求平行或垂直关系，用法向量条件联立切点坐标求解。

## 核心公式

$$\nabla F(P)\cdot(X-P)=0,\quad X=P+t\nabla F(P);\qquad z-f(a,b)=f_x(a,b)(x-a)+f_y(a,b)(y-b)$$

## 易错点

- 切面要过切点；只写梯度点乘X=0一般会漏常数。
- 含xy的复合三角函数对x和y求导分别带y和x。
- 法线参数式允许方向分量为零；不要在对称式中除以零。
- 曲面的法线和空间曲线的切线、法平面不是同一个对象。

## 真题原创讲解：2013-301-02

[题目条件、来源与题型归属](../questions/2013-301-02.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

求曲面x²+cos(xy)+yz+x=0在P=(0,1,−1)处的切平面。

$$F(x,y,z)=x^2+\cos(xy)+yz+x,\quad P=(0,1,-1)$$

### 核查切点及光滑性

F是光滑函数，代P得0+1−1+0=0，给定点确在曲面上。

$$F(P)=0$$

### 求梯度并代点

对cos(xy)分别按链式法则求导；对yz求y导得z，求z导得y。代点后梯度非零，切平面存在。

$$F_x=2x-y\sin(xy)+1,\quad F_y=-x\sin(xy)+z,\quad F_z=y,\quad \nabla F(P)=(1,-1,1)$$

### 写过切点的平面

把法向量与位置增量点乘为零，展开后代P再检验。

$$x-(y-1)+(z+1)=0,\qquad x-y+z=-2$$

## 补充推导与教学边界

教学延伸（原题只求切面）：法线参数式为 $(x,y,z)=(0,1,-1)+t(1,-1,1)$。对自编显式曲面 $z=x^2+y^2$ 在 $(1,0,1)$，法向量 $(2,0,-1)$，切面 $z-1=2(x-1)$，法线 $(1,0,1)+t(2,0,-1)$；用参数式避免中间分量为零时的非法除法。
