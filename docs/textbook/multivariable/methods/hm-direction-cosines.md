# 单位向量与方向余弦：本章复用说明

既有方法 ID：`hm-direction-cosines`，归属空间几何章。此页只说明它如何支持方向导数，不修改原方法卡、归属或核验关联。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

## 定义与几何理由

非零向量 $v=(a,b,c)$ 的模为 $\|v\|=\sqrt{a^2+b^2+c^2}$。与它同向的单位向量为

$$e=\frac{v}{\|v\|}=(\cos\alpha,\cos\beta,\cos\gamma),$$

其中 $\alpha,\beta,\gamma\in[0,\pi]$ 分别是 $v$ 与三个坐标正轴的夹角。以x轴单位向量 $i$ 为例，点积定义给 $\cos\alpha=(v\cdot i)/(\|v\|\|i\|)=a/\|v\|$，其余同理。

因此方向余弦满足 $\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1$。零向量没有方向余弦；反向向量的三个余弦同时变号。

## 可执行步骤与选择依据

1. 由题面确定有向向量；从A指向B应取 $B-A$，不要只取某条无向直线的任意方向。
2. 检查向量非零并求模长。
3. 各分量除以模，核对平方和为1。
4. 将所得单位向量送入 [梯度点积公式](hm-direction-gradient.md)，而不是把原向量直接送入。

## 自编前置算例

给向量 $v=(1,2,2)$：$\|v\|=3$，所以 $e=(1/3,2/3,2/3)$；方向余弦的平方和为 $1/9+4/9+4/9=1$。不必计算三个反余弦，方向导数只需要它们的余弦值。

再取自编线性函数 $f=4x+y$。它的梯度是 $(4,1,0)$，沿 $e$ 的方向导数为 $4/3+2/3=2$。沿原向量参数路径 $P+tv$ 的复合函数导数却是6，因为每单位参数走过3单位距离。单位化把参数速度转换成每单位距离的变化率。

## 真题衔接与核验边界

[2017年数学一第3题](../questions/2017-301-03.md) 给 $f=x^2y+z^2$、$P=(1,2,0)$ 和方向 $(1,2,2)$。上面的单位化直接给方向余弦 $(1/3,2/3,2/3)$；在指定点求偏导得梯度 $(4,1,0)$，点积为 $4/3+2/3=2$。所以该工具负责把题给方向变成每单位距离的方向，随后由梯度完成计算。完整分步讲解位于 [方向导数方法](hm-direction-gradient.md)。不把该题对梯度方法的 verified 状态自动复制到 `hm-direction-cosines`，不增加本方法的核验频次。

方向余弦中有零分量完全合法；只有总向量为零才没有方向。若题目给方向余弦本身，只需检查平方和为1，无须再次任意归一化错误数据。
