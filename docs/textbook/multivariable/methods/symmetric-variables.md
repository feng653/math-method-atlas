# 用对称变量换元降维

目标与约束关于 $x,y$ 对称时，尝试 $s=x+y,p=xy$。改写表达式后，还要用实根条件 $s^2-4p\ge0$ 以及原约束确定可行范围。

**真题中的降维：[2015 年数学一第 17 题](../questions/2015-301-17.md)。** 对 $f=x+y+xy$，在 $x^2+y^2+xy=3$ 上求各点最大方向导数的最大值。

由[梯度范数工具](gradient-norm-optimization.md)，目标可化为最大化 $(1+x)^2+(1+y)^2$。对称变量给出

$$
\begin{aligned}
s^2-p&=3,\quad p=s^2-3,\\
(1+x)^2+(1+y)^2&=2+2s+s^2-2p\\
&=9-(s-1)^2.
\end{aligned}
$$

$x,y$ 是 $t^2-st+p=0$ 的实根，所以

$$
s^2-4p=12-3s^2\ge0\iff s\in[-2,2].
$$

反过来，这个区间内每个 $s$ 的实根都满足原约束，故范围没有扩大。最大平方范数为 $9$，在 $s=1,p=-2$ 时取到，即 $(x,y)=(2,-1)$ 或 $(-1,2)$。

因此最大方向导数为 $3$，对应方向分别为 $(0,1)$、$(1,0)$。只改写成 $s,p$ 而不确定实根范围，会把不可行的代数点混进优化。
