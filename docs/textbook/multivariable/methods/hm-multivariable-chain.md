# 多元复合函数求导

既有方法 ID：`hm-multivariable-chain`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

按变量依赖累加一阶贡献；高阶求导同时追踪外函数、内函数与已有导数系数的变化。

## 直觉与选择依据

总变化来自每条依赖路径；第二次求导时，传递变化的系数本身也会变化。

由df=f_u du+f_v dv和du=u′dx、dv=v′dx得到一阶链式。再次求导产生外函数曲率与路径曲率两组贡献。

向量写法z″=w′ᵀH_fw′+∇f·w″，其中w=(u,v)。非直线路径一般不能丢第二组项。

## 符号

- **f_u、f_v**：外函数对两个参数的偏导，均在(u(x),v(x))处取值。
- **u′、u″**：内变量沿自变量变化的一阶、二阶导数。
- **H_f**：外函数二阶偏导组成的Hessian矩阵。

## 适用条件与边界

- 一阶链式要求内层映射在自变量点可微，外层函数在对应内变量点可微。
- 所列二阶对称公式可在内外函数均为C²的邻域使用；没有正则性不能擅自交换混合偏导。
- 抽象外函数不需显式表达式，但必须保留偏导的参数位置及最后取值点。

## 可执行步骤

1. 另命名内变量u、v，画出自变量到u、v再到输出的全部路径。
2. 对每条路径乘导数，再把贡献相加；有直接出现的自变量时也算一条路径。
3. 第二次求导对每个乘积使用乘积法则，对f_u、f_v继续使用链式法则。
4. 通式推导完成后，再代入自变量点，同时换算外函数的取值点；用显式可算特例复核。

## 核心公式

$$z_x=f_u u_x+f_v v_x,\quad z_{xx}=f_{uu}u_x^2+2f_{uv}u_xv_x+f_{vv}v_x^2+f_u u_{xx}+f_v v_{xx}$$

## 易错点

- f_u是外函数对第一参数求导，不是复合函数对x求导。
- 太早把u′或v′在点处的值代成常数，会漏掉u″、v″贡献。
- 二阶式既有交叉项，也有路径自身二阶变化项。
- 求混合偏导时固定的是独立变量，不能误把中间变量固定。

## 真题原创讲解：2017-301-15

[题目条件、来源与题型归属](../questions/2017-301-15.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

外函数f具有二阶连续偏导，令y=f(eˣ,cos x)，计算x=0处的一阶、二阶导数。

$$u=e^x,\quad v=\cos x,\quad (u(0),v(0))=(1,1)$$

### 先求一阶通式

先保留x，所有外函数偏导在(eˣ,cos x)处。

$$y\prime=e^x f_u-\sin x f_v$$

### 对全部因子再次求导

第一项要对eˣ和f_u分别求导；第二项要对−sin x和f_v分别求导。用f_uv=f_vu合并交叉项。

$$y\prime\prime=e^{2x}f_{uu}-2e^x\sin x f_{uv}+\sin^2x f_{vv}+e^x f_u-\cos x f_v$$

### 同时代入自变量与内变量点

x=0时eˣ=1、sin x=0、cos x=1。注意虽然v′(0)=0，v″(0)=−1仍贡献−f_v。

$$y\prime(0)=f_u(1,1),\qquad y\prime\prime(0)=f_{uu}(1,1)+f_u(1,1)-f_v(1,1)$$

## 补充推导与教学边界

混合高阶的可执行公式：对 $z(x,y)=f(u(x,y),v(x,y))$，先对 $x$ 再对 $y$ 求导，可得 $$z_{xy}=f_{uu}u_xu_y+f_{uv}(u_xv_y+v_xu_y)+f_{vv}v_xv_y+f_u u_{xy}+f_v v_{xy}.$$ 自编复核：$f=u^2+v^2,u=x^2+y,v=xy$，得 $z_x=4x(x^2+y)+2xy^2$，$z_{xx}=12x^2+4y+2y^2$；直接展开 $z=(x^2+y)^2+x^2y^2$ 求导得到相同结果。
