# 拉格朗日乘子与闭域最值

既有方法 ID：`hm-lagrange-multipliers`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

在正则等式约束下联立梯度平行关系寻找候选点，再用边界比较或全局不等式完成最值证明。

## 直觉与选择依据

约束允许的切向移动不能在极值点带来一阶增益，因此目标梯度落在约束的法向方向上。

沿可行曲线求导，约束梯度与切向量垂直；极值处目标梯度也与所有可行切向量垂直，故两者平行。

对正权重二次目标且线性约束的问题，乘子法能找最优比例，柯西不等式可直接给全局下界，是互相复核的两条路线。

## 符号

- **λ**：拉格朗日乘子，用来表达目标梯度与约束梯度的线性关系。
- **可行点**：同时满足等式以及正性、区间等全部限制的点。
- **正则约束**：约束梯度非零，多约束时梯度线性无关。

## 适用条件与边界

- f、约束g在候选点附近C¹且∇g≠0时，约束内的局部极值满足乘子方程。
- 多个约束要求其梯度线性无关；不满足时奇异可行点另查。
- 不等式边界、角点、变量不能为零的限制必须单独记录；乘子法不自动处理全部情况。
- 方程解只是候选点；开域或无界域不能直接套连续函数在紧集上取得最值。

## 可执行步骤

1. 选取变量并准确列出目标f、等式约束g=0及正性或区间限制。
2. 验证约束正则，联立∇f=λ∇g和g=0，保留满足可行条件的全部候选点。
3. 遇约束奇异点、边界或端点单独分析；若有多个候选点先比较函数值。
4. 用紧集存在性加完整候选集，或配方、凸性、不等式证明全局性。
5. 回到原问题换算变量、单位与等号条件，并区分最值和不能取到的上确界。

## 核心公式

$$\nabla f=\lambda\nabla g,\quad g=0;\qquad \nabla f=\sum_{i=1}^{m}\lambda_i\nabla g_i\ \text{（约束梯度线性无关）}$$

## 易错点

- 乘子必要条件不是极值充分条件。
- 除变量前先查其是否可能为零，避免漏解。
- 正长度约束给开单纯形，不可直接说它闭有界。
- 最后需要证明所求候选值在全部可行点中最优，不能仅凭“解唯一”。

## 真题原创讲解：2018-301-16

[题目条件、来源与题型归属](../questions/2018-301-16.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

将2米铁丝分成三段，分别围成圆、正方形和正三角形。设三段周长a、b、c均为正，求面积和的最小值。

$$a+b+c=2,\quad a,b,c>0,\quad S=\frac{a^2}{4\pi}+\frac{b^2}{16}+\frac{c^2}{12\sqrt3}$$

### 从周长推出面积

圆半径a/(2π)；正方形边长b/4；正三角形边长c/3。分别代面积公式得到题设目标，约束梯度(1,1,1)非零。

$$S_{\rm circle}=\pi(a/(2\pi))^2,\quad S_{\rm square}=(b/4)^2,\quad S_{\rm triangle}=\frac{\sqrt3}{4}(c/3)^2$$

### 联立乘子方程

设g=a+b+c−2。三个偏导等于同一乘子，由此解出候选比例。记D=π+4+3√3。

$$\frac a{2\pi}=\frac b8=\frac c{6\sqrt3}=\lambda,\quad a:b:c=\pi:4:3\sqrt3,\quad (a,b,c)=\frac2D(\pi,4,3\sqrt3)$$

### 证明全局下界且可达到

原正长度可行域是开单纯形，不能直接用紧集定理。改用柯西不等式，任意可行三元组的面积和都至少为1/D；等号条件恰为上述正比例，候选点在原域内。

$$(a+b+c)^2\le\left(\frac{a^2}{\pi}+\frac{b^2}{4}+\frac{c^2}{3\sqrt3}\right)(\pi+4+3\sqrt3)=4SD,\quad S\ge\frac1D$$

### 写最小值与单位

三段均为正且和为2米，故等号确实可取；最小面积和为下式，单位平方米。

$$S_{\min}=\frac1{\pi+4+3\sqrt3}\ \mathrm{m}^2$$

## 补充推导与教学边界

### 自编边界检查例

在闭圆盘 $x^2+y^2\le4$ 上求 $f=x^2+y^2-2x$ 的最值。内部驻点 $(1,0)$ 的值为 $-1$；边界取 $g=x^2+y^2-4=0$，乘子条件为 $(2x-2,2y)=\lambda(2x,2y)$。若 $y\ne0$ 则 $\lambda=1$，第一式矛盾，故 $y=0,x=\pm2$，边界值分别为0、8。紧集上连续保证最值存在，完整比较后全局最小为 $-1$、最大为8。

奇异约束自编反例：$x^2+y^2=0$ 只有原点，目标 $f=x$ 在该可行集上既最大又最小，但 $\nabla g(0)=0$，乘子方程无解。这正是必须单查奇异点的原因。
