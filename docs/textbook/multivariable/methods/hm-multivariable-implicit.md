# 多元隐函数与方程组求导

既有方法 ID：`hm-multivariable-implicit`。审校状态：已由主 agent 交叉审校，范围与证据见[审校记录](../review.md)。

把隐函数关系视为恒等式求微分，解关于未知导数的线性方程；方程组使用同一雅可比矩阵。

## 直觉与选择依据

不必先解出复杂的函数表达式；小变化必须继续满足原约束，这会给未知变化量一个线性方程。

对F(x,y,z(x,y))=0求x导数，得到F_x+F_z z_x=0，非零F_z允许解出z_x。此推导依赖合法链式，定理则提供局部可解性的充分条件。

方程组对每个独立变量求导时系数矩阵相同，只改变右端，因此先组矩阵能避免重复消元与符号错误。

## 符号

- **F_z**：将x、y、z暂看作独立变量后，对第三变量的偏导。
- **J**：方程组对被解出变量的雅可比矩阵；可逆时导数系统有唯一解。
- **dz**：隐函数z(x,y)的一阶变化模型。

## 适用条件与边界

- 通用充分条件：F在基点附近C¹、F=0且F_z≠0，可局部唯一解出C¹函数z(x,y)。
- 若题目已给可微隐函数关系，可按题设链式求导；不可把题目只给的“可微”改写成“偏导连续”。
- 方程组要检查对被解出变量的雅可比行列式非零；二阶展开需相应二阶光滑性。
- F_z=0只表明此公式或定理不能直接用，不足以断言隐函数不存在。

## 可执行步骤

1. 把等式移项成F=0，明确独立变量与待解函数，先代基点求函数值。
2. 检查局部可解条件或明确题目已给的可微隐函数；区分普通偏导F_x与复合后的总导数。
3. 对恒等式取全微分，收集dz系数；求单个偏导时固定另一独立变量。
4. 方程组将du、dv系数排成矩阵，分别以dx、dy系数解线性系统。二阶导数继续对原恒等式求导并代入已求一阶导。

## 核心公式

$$F_x\,dx+F_y\,dy+F_z\,dz=0,\quad z_x=-F_x/F_z,\quad z_y=-F_y/F_z$$

## 易错点

- F_x求导时把z当独立参数固定；对F(x,y,z(x,y))求导才出现F_z z_x。
- 隐函数是局部分支，必须先查该点实际满足方程。
- 求导后才能代点；因x²使某项一阶消失，不代表它所有阶导数均消失。
- 方程组不能逐个独立套单方程分式；未知导数通常互相耦合。

## 真题原创讲解：2016-301-11

[题目条件、来源与题型归属](../questions/2016-301-11.md)。以下解答独立推导；保留题目稳定 ID，不复制第三方解析。

已给隐函数z=z(x,y)满足(x+1)z−y²=x²f(x−z,y)，其中f可微，求在(0,1)处的全微分。

$$(x+1)z-y^2=x^2f(x-z,y)$$

### 确定基点

代x=0、y=1，右侧为零，得到z=1。外函数对应的参数点为(−1,1)。

$$z(0,1)=1$$

### 先由余项保证一阶展开

对题给经过基点的局部连续分支，f可微故连续，f(x−z,y)在基点附近有界。重排等式后，后一项为O(x²)，前一项在(0,1)展开为1−x+2(y−1)+O(x²+(y−1)²)，因此z可微。这不要求f为C¹，也没有据此宣称全局唯一分支。

$$z=\frac{y^2}{1+x}+\frac{x^2}{1+x}f(x-z,y)=1-x+2(y-1)+O(x^2+(y-1)^2)$$

### 对恒等式求全微分复核

对左侧用乘积法则；右侧同时微分x²和复合f。上一展开保证z在基点可微，使此处链式计算有效。

$$z\,dx+(x+1)\,dz-2y\,dy=2xf(x-z,y)\,dx+x^2\{f_1(x-z,y)(dx-dz)+f_2(x-z,y)\,dy\}$$

### 在基点解出微分

基点x=0使右侧一阶微分各项为零；左侧代入z=1、y=1，得到dz+dx−2dy=0。

$$\left.dz\right|_{(0,1)}=-dx+2dy,\quad z_x(0,1)=-1,\quad z_y(0,1)=2$$

## 补充推导与教学边界

### 自编隐方程组：具体组矩阵求解

设 $u+v=x+y, u^2+v=x-y$，在 $(x,y,u,v)=(0,0,0,0)$ 附近解出 $u,v$。左端均为多项式，且

$$J=\begin{pmatrix}1&1\\2u&1\end{pmatrix},\qquad\det J=1-2u,\qquad\det J(0)=1\ne0.$$

对 $x$ 求导：$u_x+v_x=1,2u u_x+v_x=1$；在基点得 $v_x=1,u_x=0$。对 $y$ 求导：$u_y+v_y=1,2u u_y+v_y=-1$；得 $v_y=-1,u_y=2$。所以 $du=2dy,dv=dx-dy$。这是真实的耦合系统，不能把两个方程分别当成两个独立隐函数。

### 二阶导数如何继续

若 $F\in C^2$ 且 $F_z\ne0$，对 $F_x+F_z z_x=0$ 再求 $x$ 导数，逐项得

$$F_{xx}+2F_{xz}z_x+F_{zz}z_x^2+F_z z_{xx}=0.$$

因此 $z_{xx}=-(F_{xx}+2F_{xz}z_x+F_{zz}z_x^2)/F_z$。含 $z_x$ 的系数本身也沿隐函数变化。原题只给可微，并不授权对它使用此C²拓展公式。
