# 一元积分何时转成二重积分

目标通常是求值、证明积分等式或计算面积。先判断转换能否产生简单的内积分、可利用的对称性或更好描述的区域。

## 按结构选择

| 识别信号 | 可选方法 | 使用前核对 |
| --- | --- | --- |
| $(b-x)f(x)$、$(x-a)f(x)$ | [把积分权重写成区间长度](../../methods/weight-as-length.md) | 长度对应哪一条切片，上下限方向是否正确 |
| $\int[\int f]$，内层原函数难求 | [对变限积分换序以避开难求原函数](../../methods/change-order.md) | 写成区域不等式，换序是否需要分段 |
| $f(x)\int_a^x f(t)dt$ | [把对称三角域补成正方形](../../methods/symmetric-product.md) | 交换变量后核不变，两半只在对角线重合 |
| 圆形根式、面积或闭曲线 | [把一元积分转为面积或边界积分](../../methods/geometry.md) | 非负性、极坐标范围、雅可比或格林条件 |

## 自编例题的选择过程

对于

$$
I=\int_0^1\left[\int_x^1 e^{t^2}\,dt\right]dx,
$$

直接求内层初等原函数不方便；区域为 $0\leq x\leq t\leq1$，换序后先对不出现在核中的 $x$ 积分，得到 $\int_0^1t e^{t^2}dt=(e-1)/2$。这就是从“难在哪”倒推“换序能否简化”。也可把内层记为 $F(x)$ 后分部积分，两种路线均可。

## 作答时需要写出的三件事

1. **条件与区域：** 说明核在所用有限区域上连续，写出完整区域；有奇点时另行证明合法性。
2. **变换后的积分：** 同时改变积分次序与积分限，或在坐标变换后乘雅可比。
3. **回到原目标：** 面积是否有正负、曲线是否反向、补边是否需要扣除，最后用简单界或另一种方法复核。

如果原积分用换元、分部或凑微分已经很短，可直接采用一元解法。不要仅为了使用“升维”而增加计算步骤。
