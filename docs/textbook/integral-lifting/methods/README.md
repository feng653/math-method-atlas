# 积分升维与换序工具箱

按原式结构选择，优先检查有限区间连续条件和积分区域。

1. [把积分权重写成区间长度](weight-as-length.md)：一次权重与三角区域互换，适合恒等式证明。
2. [对变限积分换序以避开难求原函数](change-order.md)：重新描述同一区域，先积容易的变量；边界切换时分段。
3. [把对称三角域补成正方形](symmetric-product.md)：核与交换变量的对称性配合，把累次积分变成平方。
4. [把一元积分转为面积或边界积分](geometry.md)：图下面积、半圆极坐标和椭圆格林公式。

前三项分别与分部积分、变上限积分求导、凑微分相互复核。第 4 项需要识别几何区域，并在使用格林公式前检查闭合、定向与光滑性。全部例题均为自编。
