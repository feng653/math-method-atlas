# 用 Leibniz 公式留下非零项

两因子有到 $n$ 阶导数时，把 $n$ 次求导分配给两边，再乘组合数。多项式因子高阶导为零，宜先列存活项。

**自编例。** 求 $x^2e^x$ 的 $n$ 阶导数，$n\ge2$。多项式只有零、一、二阶导数不恒为零：

$$
\begin{aligned}
(x^2e^x)^{(n)}
&=x^2e^x+\binom n1(2x)e^x+\binom n2\,2e^x\\
&=e^x[x^2+2nx+n(n-1)].
\end{aligned}
$$

特别地，零点值为 $n(n-1)$。组合数表示求导次序的不同安排，不能漏掉；零阶导数就是函数本身，不是零。
