# 左右分别写差商，再比较

分段点在定义域内部时，分别让增量从负、正方向趋零。两侧差商必须有限且相等；两边都发散也不能判可导。

**真题局部任务：[2019 年第 2 题](../questions/2019-301-02.md)。** 根据既有摘录，零点左邻域为 $-x^2$，右邻域为 $x\ln x$，且 $f(0)=0$。这里只判断零点可导性，不补写原题选项。

$$
f'_-(0)=\lim_{h\uparrow0}\frac{-h^2}h=0,
\qquad
\frac{f(h)-f(0)}h=\ln h\longrightarrow-\infty\quad(h\downarrow0).
$$

右侧没有有限导数，因此零点不可导。虽然如此，右侧函数值仍趋于零，函数在零点连续。

不要把右支导函数 $\ln x+1$ 的极限直接称为右导数；本题应先按差商完成判断。原题的极值任务见[一阶变号](first-derivative-extremum.md)。本例沿用仓库摘录条件，未重新核验外部题面。
