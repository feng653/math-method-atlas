# 2013 年数学一第 18 题

证明一阶导数和导数组合取指定值。

## 任务与条件摘要

两个已记录任务分别是取得指定一阶斜率和证明两阶导数组合取值。奇性可提供基点与导数对称信息；后一个任务可倒推指数权函数，使其导数包含目标组合。
