# 2015 年数学一第 18 题

从差商证明两因子及多因子求导式。

阅读入口：[从定义证明求导法则](../problem-types/derivative-rule-proof/index.md)。

## 任务与条件摘要

先用加减同一项拆开两因子的差商，并用可导蕴含连续取极限；再把双因子结论用于有限乘积归纳。该任务不要求高阶可导，不应误归为高阶 Leibniz 公式。
