# 2012 年数学一第 2 题

求零因子乘积在指定点的导数。

阅读入口：[求显式函数的一阶导数与微分](../problem-types/explicit-first/index.md)。

## 任务与条件摘要

指定点的一个因子为零，乘积法则代点后只保留相应项。这里不满足对整个乘积取对数的非零条件，不应把旧工具名称当作选法依据。
