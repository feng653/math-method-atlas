# 2014 年数学一第 1 题

依据极限定义辨认渐近线。

阅读入口：[求竖直、水平和斜渐近线](../problem-types/asymptotes/index.md)。

## 任务与条件摘要

检查函数与候选直线的差是否趋零。剩余项有界但持续振荡时不足以给出渐近线；正负无穷方向必须分别讨论。
