# 2010 年数学一第 16 题

求含参变限积分函数的极值。

阅读入口：[判断变限积分函数的单调性与极值](../problem-types/integral-function-behavior/index.md)、[求局部极值及极值参数条件](../problem-types/local-extrema/index.md)。

## 任务与条件摘要

先把含有自变量的被积表达式拆为外系数乘变上限积分与另一个积分。边界项抵消后再列导数符号；拆分合法性及被积函数连续区间须由完整题面确认。
