# 2023 年数学一第 17 题

由切线截距关系求曲线并求积分函数最值。

阅读入口：[求切线法线或由切线关系建立方程](../problem-types/tangent-normal/index.md)、[判断变限积分函数的单调性与极值](../problem-types/integral-function-behavior/index.md)、[求给定区间最值或恒成立参数范围](../problem-types/global-extrema/index.md)。

## 任务与条件摘要

第一项将切线点斜式和截距条件化为微分方程，求解跨到微分方程章。第二项把积分函数求导为被积函数并判变号，全局结论须结合题设定义域，不能只报告驻点。
