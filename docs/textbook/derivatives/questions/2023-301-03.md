# 2023 年数学一第 3 题

判断参数表示在零点的可导性。

阅读入口：[判断指定点可导性及分段参数](../problem-types/point-differentiability/index.md)、[求参数曲线斜率与一阶导数](../problem-types/parametric-first/index.md)。

## 任务与条件摘要

摘要说明零参数处含绝对值，只在参数非零两侧使用常规参数公式。零点回到图像增量与左右差商判断，不能把奇异参数点直接带入导数比。
