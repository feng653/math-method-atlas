# 2014 年数学一第 16 题

求隐函数的局部极值。

阅读入口：[求隐函数或反函数导数](../problem-types/implicit-inverse/index.md)、[求局部极值及极值参数条件](../problem-types/local-extrema/index.md)。

## 任务与条件摘要

摘录提供隐式求导的分母在曲线上为正，以及唯一候选驻点的线索。先证明分母不为零，再用曲线上相关组合的左右符号判断导数变号，不能只解驻点方程便宣布极值。
