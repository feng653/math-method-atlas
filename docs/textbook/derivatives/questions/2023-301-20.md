# 2023 年数学一第 20 题

证明二阶导中值关系与下界。

阅读入口：[证明区间内存在导数等式点](../problem-types/mean-value-existence/index.md)、[证明导数幅值或增量的界](../problem-types/derivative-bound/index.md)、[求局部展开、近似及误差界](../problem-types/local-approximation/index.md)。

## 任务与条件摘要

在目标点两侧作带余项展开，分别保留余项点。若要合并为一个中间点，需明确二阶导连续性及加权范围；两个余项点不天然相同。
