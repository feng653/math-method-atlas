# 2017 年数学一第 2 题

由函数和导数的乘积比较平方值。

阅读入口：[判断单调性并比较函数值](../problem-types/monotonicity/index.md)。

## 任务与条件摘要

把乘积符号解释为平方函数的导数符号，进而比较平方值。若目标涉及原函数本身，还需知道其符号；平方大小不能自动恢复原函数的大小次序。
