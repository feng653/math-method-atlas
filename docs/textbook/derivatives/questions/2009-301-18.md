# 2009 年数学一第 18 题

证明中值等式及端点右导数结论。

阅读入口：[证明区间内存在导数等式点](../problem-types/mean-value-existence/index.md)、[由已知极限或函数关系求点上导数](../problem-types/recover-derivative/index.md)。

## 任务与条件摘要

第一项任务可由函数减去端点割线构成等端值函数；第二项要让区间端点趋近研究点，并用连续性接上真实点值。仅有邻域导数极限时还须补上端点连续条件。
