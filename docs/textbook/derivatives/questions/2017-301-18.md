# 2017 年数学一第 18 题

证明原函数零点和导数组合零点存在。

阅读入口：[证明函数或高阶导数零点存在](../problem-types/higher-zero-existence/index.md)。

## 任务与条件摘要

已记录的两项任务先由端点及近零符号得到原函数零点，再对平方或适当辅助表达式应用 Rolle。异号结论使用连续性；导数组合的存在需要明确辅助函数和等端值。
