# 求平面曲线曲率与曲率半径

先选择显式或参数表示，并检查二阶光滑和正则性。曲率取绝对值；只有曲率正时才能取倒数为有限曲率半径，参数速度为零时公式不适用。

可选工具：[显式曲线曲率计算](../../methods/explicit-curvature.md)、[参数曲线曲率计算](../../methods/parametric-curvature.md)。
