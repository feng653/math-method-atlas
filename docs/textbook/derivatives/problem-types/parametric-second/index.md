# 求参数曲线二阶导数

先得到一阶斜率，再对参数求导，最后除以横坐标的一阶参数导数。要求局部所需二阶导数存在及横坐标导数非零，不能使用两个二阶参数导数之比。

可选工具：[参数二阶导数算子](../../methods/parametric-second.md)。
