# 求高阶导数及指定点导数值

乘积适合 Leibniz，周期或幂函数结构适合归纳。已知函数具有目标阶导数时才可从 Taylor 系数读值；只有一个渐近等式不能反推高阶可导。

可选工具：[Leibniz 高阶乘积求导](../../methods/leibniz-rule.md)、[基本函数高阶导数归纳](../../methods/nth-derivative-pattern.md)、[由 Taylor 系数提取已存在的导数](../../methods/taylor-coefficient.md)。
