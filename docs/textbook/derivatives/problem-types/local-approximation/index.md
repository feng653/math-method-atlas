# 求局部展开、近似及误差界

局部主项只描述趋近时的阶；要给固定区间上的误差上界，必须另有余项导数界。插值误差可选展开中心和权重抵消低阶项；积分误差还需积分估计。

可选工具：[Taylor 首个非零项比阶](../../methods/taylor-leading-term.md)、[Taylor 余项估计误差](../../methods/taylor-error-bound.md)。
