# 求参数曲线斜率与一阶导数

研究参数点的横坐标导数非零时，才能直接求纵横导数比。奇异参数点可另由增量比判断图像，不能只看到分母为零便宣布没有切线。

可选工具：[参数一阶导数比](../../methods/parametric-first.md)、[左右差商判可导](../../methods/one-sided-difference.md)。
