# 证明凸性、割线或积分平均命题

不等式命题先核对点序及分母合法性。可导时联系割线和导数的单调性，二阶光滑时可用对称 Taylor 增量；严格不等式还需单独排除等号。

可选工具：[三点割线比较判凸性](../../methods/convex-secant.md)、[对称增量比较与二阶展开](../../methods/symmetric-increment.md)、[Lagrange 中值式控制增量](../../methods/lagrange-increment.md)。
