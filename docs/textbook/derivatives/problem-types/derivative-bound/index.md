# 证明导数幅值或增量的界

围绕端点或函数绝对值最大点分割区间，逐段使用中值式。涉及等号或严格界时需追踪每段取等条件；高阶导数界可借两侧 Taylor 余项，余项点不能擅自合并。

可选工具：[Lagrange 中值式控制增量](../../methods/lagrange-increment.md)、[Taylor 余项估计误差](../../methods/taylor-error-bound.md)。
