# 判断指定点可导性及分段参数

遇到拼接点、根号、绝对值或取整结构时，先保留实际点值，分别算左右差商。邻域公式可求导不代表连接点可导；要求两侧极限相等且有限。

可选工具：[定义差商求导数](../../methods/difference-quotient.md)、[左右差商判可导](../../methods/one-sided-difference.md)、[Taylor 首个非零项比阶](../../methods/taylor-leading-term.md)。
