# 一元微分概念篇交接

正文为 [concepts.md](concepts.md)，已完成概念作者初稿。按导数 → 可微 → 表示方式与高阶导 → 中值定理 → 洛必达 → Taylor → 定性与几何应用组织，共 12 节。

## 统一口径

- 导数存在指有限导数，普通导数采用双侧定义；端点使用单侧定义。左右差商须减去实际函数值。
- 一元可导与可微等价；导数连续是更强条件。反函数使用明确的局部 C¹ 充分条件，不能当作必要条件。
- 中值定理区分闭区间连续与开区间可导；Cauchy 先给不除法版本，除法另加分母条件。
- 洛必达使用“0/0 或分母绝对值趋于无穷”的充分条件版本，后者不额外要求分子极限。每次使用均需检查导数商极限与非零分母导数；双侧必须分别确认。
- Taylor 分别写 Peano、Lagrange、Cauchy、积分余项。Peano 不要求多一阶导数；积分余项为跨章提醒，不在本章重讲积分。
- 单调不减与严格递增分开。驻点只给极值候选，一阶变号判据不被表述为一般极值的必要条件。
- 凸统一指图形在弦下方，二阶可导时对应 f″≥0；若题源用相反中文名称，必须显式转换。拐点按凹凸变化定义，允许该点无有限导数。
- 渐近线在正负无穷方向分别判断；斜率有限不代表截距存在。曲率零不等于拐点。

## 建议细分题型

下列是按作答目标提出的候选，题型作者应结合可核对题面调整，不能按工具数量倒推题型。

1. 在指定点判断可导、求导数或确定分段参数。
2. 由差商、函数关系或已知极限反求导数。
3. 求显式复合函数的一阶导数与微分。
4. 求隐函数、反函数或参数曲线的导数。
5. 求高阶导数或指定点的高阶导数值。
6. 求切线、法线及其满足的几何条件。
7. 证明至少存在一个满足导数等式的中间点。
8. 证明多个零点、导数零点或零点个数限制。
9. 求适合微分工具处理的未定式极限。
10. 求局部展开、近似值或误差界。
11. 判断单调区间、证明不等式或函数方程根的唯一性。
12. 求驻点、局部极值及参数条件。
13. 求闭区间最值或带实际约束的一元最优化。
14. 判断凹凸区间、求拐点或讨论图形形态。
15. 求曲率、曲率半径或指定几何量。
16. 求水平、竖直和斜渐近线。

## 建议原子工具

工具作者应在题型作者交接后再写。工具按可执行动作拆分，不把“求导”“导数应用”当作一个完整工具。

- 定义差商；左右差商拼接；在连续条件下由邻域导数极限判定单侧导数。
- 四则求导；链式求导；对数求导；反函数求导；隐式恒等式逐次求导；参数导数算子。
- Leibniz 高阶乘积求导；基本函数高阶求导归纳；由局部 Taylor 系数提取导数（先确保相应可导性，不能从任意渐近展开反推高阶可导）。
- Rolle 直接应用；Rolle 辅助函数构造；重复 Rolle；Lagrange 增量估计；Cauchy 比值中值式。
- 洛必达一次应用及逐轮条件检查；幂指型取对数；Taylor 主项比阶；Taylor 余项估计。
- 导数符号表；一阶变号极值判别；二阶极值判别；高阶首个非零导数判别；闭区间候选值比较。
- 构造差函数证明不等式；导数单调结合端点符号控制零点个数。
- 二阶导符号判凹凸及拐点；切线方程；法线方向；显式曲率；参数曲率；渐近线依次取极限。

跨章工具可链接既有先修文章，避免重写极限四则、等价无穷小或积分方法。没有来源支持的示例须明确标自编。
