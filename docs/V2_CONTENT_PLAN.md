# V2：从题目目标到有限方法清单

用户的积分三类是示例，不是封闭分类；后续明确补入等式证明。题型以“要求求出或证明什么”划分，方法以“执行什么基本操作”划分；一道复合题可对应多个题型，一个方法可服务多个题型。

## 内容层级与编辑

章节→题型→可选方法。题型独立保存在各体系problem-types目录，每文件一题型；稳定ID引用既有方法，不复制方法卡。每题型记录识别特征、检查顺序、全部已列候选方法及选择条件、二级公式、真题ID和边界。公式必须附条件、推导和基本方法引用。题型方法清单是可检验、可补缺的有限清单，不承诺数学技巧绝对穷尽。

## 分类样板

一元积分应核对：不定/定积分计算、变上限积分与相关函数、积分等式证明、积分不等式证明、反常积分敛散性、几何/物理应用、积分性质与存在性。必要时细分，不将换元或分部等操作当成与证明/计算并列的题型。等式证明需考虑换元配对、对称周期、分部与边界项、原函数同导数及初值、积分定义与极限等候选路线。

## 递进验收

1. 接入题型契约、图层、题型卡与真题入口，校验跨库/悬空引用及公式。
2. 三组内容编写覆盖22章，逐章检查现有方法是否进入至少一个合理题型；同时列出缺失基本操作，不以已有方法作为完整性的唯一依据。
3. 逐题型独立核算二级公式及条件，逐真题按实际作答目标审查归属；草案不计为已核验题型考试频次。
4. 补齐已发现基本方法与二级公式，检验典型题和边界反例；先保证积分样板的完整候选路线。
5. 取得2026课纲正文后，仍需独立逐要求核对。现有历史要求、内容数量及题型整理都不能替代此步骤。

完整内容目标保持原路线图；新增功能可以先交付草案，但必须保留具体缺口，不能将“每章有题型”写成“题型与方法全部穷尽”。
