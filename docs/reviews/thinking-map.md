## 提炼与去重规则

先看具体目标与可见条件，写出为什么需要下一步，再记录不能这样做的边界。归并按决策功能，跨科复用；不按题型或公式名称增加节点。分类并非严格先后流程，做题时可往返。

| 分类 | 触发条件 |
| --- | --- |
| 读题与转译 | 任意点的几何构造满足固定关系；出现带有隐含约束的概念关键词；目标明确，但缺少可直接使用的信息 |
| 结构与变换 | 导数与系数呈现固定组合；原表示繁琐，存在保持目标的变换；表达式接近熟悉模型，但形式尚未对齐；出现重复的多变量式子或函数组合；存在对称、线性或可消去的公共项 |
| 条件与分支 | 参数、零值或边界会改变可用条件；整体由不同情形、区域或原像组成 |
| 验证与收尾 | 直接求值困难，但目标只需证明或估计；要判断全称命题或两个概念是否等价；得到候选结果，或经历非等价变形 |

保留5个已有入口ID，增加8个决策入口。整体代换只处理重复组合；一般换表示处理换基、分解、配方等。退化分支处理条件失效；整体分块处理互斥穷尽的组成。辅助比较用于建立证明；必要条件/反例用于否定；回验处理已经得到的候选结果。基础策略保留短推演，具体技术算法继续由已有方法卡承担。

## 第29题纠错

原记录遗漏一般点P的横坐标。正确中点为((x+q)/2,y/2)，因此 y²=x+q；法线给 q=x+yy′，合并得 yy′=y²−2x。令v=y²，则v′−2v=−4x，v=Ce^(2x)+2x+1。y(0)=2给C=3，解为 y=√(3e^(2x)+2x+1)，取含0且根号内严格为正的最大连通区间。

回验：y²−yy′=2x，所以q=y²−x，中点横坐标y²/2，满足2Y²=X；y(0)=2。旧VERIFICATION中的第29题“回验成立”已明确标为失效历史记录。此次纠错只修改讨论示例及对应导数结构公式，不把用户拍摄题新增为未经确认的历年真题。
