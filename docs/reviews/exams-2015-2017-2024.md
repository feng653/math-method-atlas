## 2015

| 题号 | 独立判断 |
| --- | --- |
| 1 | 二阶导数图的符号改变才产生拐点；接触零轴而不变号不计。 |
| 2 | 将给定指数型特解代回并按指数项配系数，得到 a=−3、b=2、c=−1；只认证待定系数操作。 |
| 3 | 条件收敛给原幂级数半径 1，乘 n 不改变半径；不能假设相邻系数比极限存在。 |
| 4 | 第一象限两射线夹角固定，双曲线给极径上下界，使用极坐标并乘 r。 |
| 5 | 按参数值比较系数矩阵和增广矩阵的秩；无穷多解要求同秩且小于未知数数目。 |
| 6 | 更换正交特征向量列次序会对应重排对角项，变号不改变特征值。 |
| 7 | 事件包含关系给 P(AB)≤min(P(A),P(B))≤(P(A)+P(B))/2；仅认证概率界操作，选项字形仍损坏。 |
| 8 | 题面仅不相关；由协方差为零算混合矩，E(X²)=Var(X)+E(X)²，无需独立。 |
| 9 | ln cos x 与 −x²/2 等价，极限为 −1/2。 |
| 10 | 对称区间上分离奇函数零积分和绝对值偶函数积分。 |
| 11 | 隐式方程在题给点对 z 的偏导非零，可按隐函数偏导公式求值。 |
| 12 | 单纯形上一次函数的三重积分，可逐层积分或作轴向尺度替换。 |
| 13 | 按稀疏列展开并保留余子式符号，得到带状行列式递推。 |
| 14 | 联合正态且零相关给独立；中心化后两个半轴事件相乘。 |
| 15 | 展开到三阶，先令一次、二次系数消失再识别等价三阶项。 |
| 16 | 切线截距三角形面积转为 y'=y²/8，再用初值分离变量。 |
| 17 | 单位方向最大方向导数等于梯度模，椭圆约束下对梯度模平方用乘子法。 |
| 18 | 以差商加减同一项证明两因子乘积法则，再归纳至多因子；不要求高阶可导。 |
| 19 | 上半球和斜平面的交线只能取指定半弧，参数化后代入有向第二类线积分。 |
| 20 | 把新基写成旧基下的列矩阵，等坐标条件给齐次系统并先检查基可逆。 |
| 21 | 由相似不变量求参数，再对角化求满足相似关系的变换矩阵。 |
| 22 | 独立等待试验的成功概率由指数尾概率给出；第二次成功的试验数用前段计数与末次成功分解。 |
| 23 | 均匀区间均值反解矩估计；最大似然的端点取到问题仍需清晰题面，暂不认证该关联。 |

## 2016

| 题号 | 独立判断 |
| --- | --- |
| 1 | 分别在零点与无穷远作幂函数比较，两端可积条件都要满足。 |
| 2 | 先分段积分且对数部分分部积分，再令原函数在拼接点连续。 |
| 3 | 一阶线性方程两个特解之差为齐次解，通解是特解加其倍数。 |
| 4 | 右侧阶梯函数差商被 1 与 (n+1)/n 夹住，左差商也是 1。 |
| 5 | 相似关系可通过转置、逆及多项式传递；一般不能与转置相加后仍直接传递。 |
| 6 | 对称矩阵特征值 5、−1、−1，正交化识别二次曲面类型。 |
| 7 | 正态标准化将阈值 μ+σ² 化为 σ，结合分布函数单调性比较。 |
| 8 | 两个独立试验的互斥类别计数，用交叉矩算协方差再标准化为相关系数。 |
| 9 | 变上限积分求导后用等价量比较分子分母，极限为 1/2。 |
| 10 | 按旋度三分量定义求偏导，得到 (0,1,y−1)。 |
| 11 | 题给点隐式方程关于 z 的偏导不为零，链式求导后解出 z 的偏导。 |
| 12 | 分别展开 arctan x 与有理函数至三阶，由三阶导值确定系数。 |
| 13 | 沿稀疏首列或末行展开，得到 λ⁴+λ³+2λ²+3λ+4。 |
| 14 | 按通常正态均值中心对称双侧区间，中心 9.5、半宽 1.3，另一端为 8.2。 |
| 15 | 题面已给极坐标区域，代入 x=r cosθ 并计面积因子 r。 |
| 16 | 特征根 −1±√(1−k) 都负，指数解在正半轴可积，再结合初值求积分。 |
| 17 | 微分形式是 df，曲线积分化端点差；所得单变量函数求导判最小值。 |
| 18 | 封闭外向多面体曲面应用高斯公式，散度是 2x+1。 |
| 19 | 0<f'<1/2 使相邻差同号且绝对值几何衰减，级数比较给有界性，数列单调有界收敛；再对固定极限用中值定理约束其范围。 |
| 20 | 逐参数行消元，分别比较秩并把相容矩阵方程写成特解加齐次解。 |
| 21 | 三个互异特征值可对角化计算 A⁹⁹；由 B²=BA 归纳 B¹⁰⁰=BA⁹⁹，按列乘法解释。 |
| 22 | 指标变量 U 分割上下区域；用事件联合概率反例否定独立，按 U=0、1 的完备事件组求 Z 的分布；映射不满足二维可逆雅可比条件。 |
| 23 | 独立样本最大值分布为单个分布的三次方，积分得 E(T)=9θ/10，再取无偏倍数。 |

## 2017

| 题号 | 独立判断 |
| --- | --- |
| 1 | 右支以 1−cos√x 等价于 x/2 求极限，和拼接值比较；损坏的第二支范围不作为新增假设。 |
| 2 | 对 f² 求导得 2ff'>0，从而比较端点平方大小。 |
| 3 | 方向向量先单位化，再与题给点梯度作内积。 |
| 4 | 位置差等于初始距离加速度差的定积分；按图上有向面积判断。 |
| 5 | 单位向量张成的方向被 I−ααᵀ 消去，可直接判零特征值。 |
| 6 | 区分重特征值的特征子空间维数；可对角化者才与对应对角矩阵相似。 |
| 7 | 各事件概率严格介于 0 与 1，乘正分母将条件概率不等式化为同一个交叉乘积判据。 |
| 8 | 独立正态样本且 n≥2；离差平方和与中心化平方和分别对应 n−1 与 n 自由度。 |
| 9 | 由幂级数的三阶系数读取导数，不能把系数直接当导数。 |
| 10 | 二阶常系数方程的共轭复根给指数乘正余弦。 |
| 11 | 圆盘单连通且分母不为零，检验交叉偏导相等确定参数。 |
| 12 | 对几何级数逐项求导并匹配系数，保持收敛区间。 |
| 13 | 可逆基矩阵右乘不改变矩阵秩。 |
| 14 | 正态混合分布的期望按权重线性组合，均值为 2。 |
| 15 | 二元复合函数连续二次求导，保留二阶链式中的混合偏导与内层二阶项。 |
| 16 | 把和式整理为网格宽 1/n 的黎曼和，再对对数积分分部积分。 |
| 17 | 隐函数关于 y 的偏导恒正，求导得到驻点，再判导数符号分类。 |
| 18 | 先用端点及近零符号取零点，再对平方函数或适当辅助函数使用罗尔定理产生导数零点。 |
| 19 | 交曲线先投影得到参数边界，锥面面积元乘题给密度，不能把曲面积分当投影面积。 |
| 20 | 互异特征值给特征基，利用给定列条件确定矩阵作用并解相容线性系统。 |
| 21 | 实对称矩阵先由秩条件定参数，再用正交特征基化二次型。 |
| 22 | X 为两点离散量，Y 有连续密度；对 X 分层得移位分布混合，不能套两连续密度卷积；E(Y)=2/3。 |
| 23 | 绝对偏差是半正态，正负原像概率合并给密度；再算一阶矩和样本似然估计尺度。 |

## 2024

| 题号 | 独立判断 |
| --- | --- |
| 1 | 变上限积分先换元比较正负自变量，利用被积函数奇偶性判原函数奇偶性。 |
| 2 | 球面指定部分先核法向方向，再用方向余弦将第二类曲面积分转第一类。 |
| 3 | 对 ln(2+x) 的偶部逐项求导，组合得到 n a₂ₙ 的和。 |
| 4 | 导数存在必须使用真实点值作差商，仅有函数极限不能替代题给点值。 |
| 5 | 图中三平面共线，系数秩与增广秩均为 2，系统相容且有自由元。 |
| 6 | 整体秩为 2 与任意两向量无关须分开判断，不能由整体相关推出某一对相关。 |
| 7 | 矩阵在 α 的方向为零、在正交补为恒等，构造完整特征基后判相似和对角化。 |
| 8 | 独立正态线性组合仍正态，方差按系数平方相加。 |
| 9 | 先算 E(Y|X) 再积分得均值与 E(XY)，由此计算协方差。 |
| 10 | 先将差改为 X+(−Y) 作独立连续卷积，再对差取绝对值合并两侧；支撑决定指数分段。 |
| 11 | 先对变幂取对数，再按所需三阶展开，最后用 exp u−1 与 u 等价。 |
| 12 | 连续两次链式求导，内层一阶导在给定点为零会消去二阶偏导项。 |
| 13 | 半区间余弦系数积分求出后，利用小角正弦等价量处理奇指标极限。 |
| 14 | 令 u=x+y 将微分方程变成可分离形式，并用初值确定积分常数。 |
| 15 | 平方配方法或正定半正定条件控制参数，边界也要纳入。 |
| 16 | 独立伯努利概率先求三次全成功，再除以至少一次成功的概率。 |
| 17 | 按 x 固定切片拆圆外区域，上下限来自单位圆与外边界。 |
| 18 | 曲面偏导给切平面，再对截距构成的目标函数求驻点并检查边界及无界端。 |
| 19 | 在目标内点分别对两端作一阶泰勒展开，插值权重使一阶项抵消；余项界再积分给整体误差界。 |
| 20 | 斯托克斯公式将闭曲线积分转旋度通量，选平面片后按椭圆尺度变换并计雅可比。 |
| 21 | 把递推列向量写为矩阵幂，在特征基中计算并用矩阵乘法还原。 |
| 22 | 独立均匀样本的最大值分布给一二阶矩，无偏倍数和均方误差最优倍数分别计算。 |
