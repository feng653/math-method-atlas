## 题目变更：2011 第18题

重新读取[当前实际题面](https://www.csgraduates.com/study_methods/math/math1/2011/)的第18题。独立以积分 ∫ₙ^(n+1)dt/t 的严格端点界得对数界；因此相邻差为负。逐项用 1/k>ln(1+1/k) 累加，得到调和和大于ln(n+1)，故题中 aₙ>0。一般单调有界直接适用，不需要自治递推，也不要求求出极限常数。

## 2009 第9题：取得完整条件后升级

重读[旧题源](https://www.csgraduates.com/study_methods/math/math1/2009/)仍只见“具有连续偏导数”，却要求复合混合二阶偏导。不能从 C¹ 推出所需二阶存在，因此先保留该负面证据。

必要性的独立反例：令 f(u,v)=|u+v−1|^(3/2)，它是 C¹；复合 z=|x+xy−1|^(3/2) 在(1,0)的一阶偏导存在，而继续取所求混合导数的差商为 (3/2)(1+h)/√|h|，趋向正无穷，不存在有限极限。故不能为升级关联而擅自把题设改成 C²。

随后主 agent 提供[高校托管文登试题分析 PDF](https://lxy.zust.edu.cn/__local/5/D0/ED/BE001CD3E468023340D11150942_B9D1F5E3_9C49E.pdf?e=.pdf)线索。本 reviewer 下载并实际渲染查看第9页（PDF第9页/印刷页9），清晰题面明确写“二阶连续偏导数”，不是只依据搜索摘要。独立先得 zx=f₁+yf₂，再取 y 导数得到 xf₁₂+f₂+xyf₂₂，内层均光滑。因此获主 agent 追加授权后将 `2009-301-09` 换为该来源及 page=9，关联升级 verified。高校托管的培训机构分析文档不等同于主管部门官方原卷；本次解决的是转录遗漏的必要条件。
