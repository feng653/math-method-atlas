# 概率统计基础子要求差距复查

2026-09-08。依据[2019 高校存档课纲](https://jtb.ncbcjxau.edu.cn/uploadfile/3/Attachment/667c3cc0da.pdf)第 8–10 页概率统计一至八，重新读取缓存全文与现有方法正文；这是历史版内容差距建议，不认证 2026 完整性。判断依据是条件、公式、步骤是否足以执行，不是方法或 topic 数量。本次除卡方卡外只记录建议。

| 明列子要求 | 当前内容证据与剩余差距 | 最小建议 |
| --- | --- | --- |
| 二.1 分布函数概念与性质 | `pr-dist-cdf` 有右连续、端点概率；没有完整的单调性、两端极限与候选函数判定流程 | 扩展原卡，加入四条件和带参数分段函数合法性例 |
| 二.4 均匀分布及应用；三.3 二维均匀分布 | 期望卡只有 U(0,1) 算例，几何概型卡有面积比，边缘卡有三角域常密度例；缺少明确的一维 U(a,b) 分段 CDF 与二维区域均匀密度的统一定义及识别步骤 | 扩展密度卡和边缘卡，写明区间长度/区域面积有限且正、支持域、边缘一般不均匀，避免新建重复积分卡 |
| 三.1 多维分布概念、性质与事件概率 | 现有联合卡主要处理有密度或离散表；尚无一般二维 CDF 的矩形增量、边缘极限及含奇异分量时的基本操作 | 补一般联合 CDF 操作卡；2020 第22题可用于说明不能假设所有联合分布有密度 |
| 三.3 二维正态概率密度 | `pr-bivariate-normal` 已有参数、条件分布和线性组合，但正文没给联合密度公式及二次型指数识别流程 | 扩展原卡的非退化密度公式；保留联合正态与仅边缘正态的区别 |
| 四.1 常用分布数字特征；六.1 样本矩 | 通用求矩卡可算，但常用分布数字特征没有完整归纳；几何仅列均值，超几何未列均值方差；样本统计量卡没定义一般样本原点矩/中心矩 | 在相应分布卡补均值方差及参数约定；扩展样本卡说明原点矩与中心矩，明确二阶中心矩分母 n 与 S² 的 n−1 不同 |
| 六.2 χ²、t、F 的概念性质与上侧分位数查表 | 构造卡已有 t/F 独立性，但缺少上侧分位数与现有下尾记号的明确换算和查表例，常用性质也分散不全 | 扩展抽样卡，至少补卡方可加条件、t 对称、F 倒数交换自由度与上侧分位数换算；勿直接替换全库现行下尾约定 |
| 七.4 单总体方差区间；八.2 单总体方差检验 | 区间卡明确只写均值未知分支；检验卡仅用样本中心化的 n−1 量，虽仍可用于已知均值，但未展示使用已知真均值的 n 自由度分支 | 待卡方卡审校后扩展原区间/检验卡，以真实中心和自由度分支选择枢轴，不另起重复实现 |

已补待审：`pr-sample-chi-square` 同一卡增加真均值中心化 χ²_n、样本中心化 χ²_(n−1)、正态平方和独立分解和 n=8 双分支自编例；状态改为 draft，交主 reviewer 确认。原卡已有 n 自由度易错提示，但仅提示不足以支持操作性关联。

没有把 Welch 不等方差近似、非正态渐近方差检验等自动列为必须新增；历史课纲宽泛文字不足以据此认定特定扩展算法必考。以上为已定位的基础子要求缺口，仍不是穷尽的完整性证明。
