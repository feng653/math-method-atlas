## 逐公式条件与核算

以下名称对应JSON公式title；每条已经独立检查推导及适用条件，数值例子仅作自检，不写成真题答案。

| 题型ID末段/章节 | 核查证据 |
| --- | --- |
| determinants/evaluate | 秩一扰动列展开只保留0或1列扰动；u=(1,2)、v=(3,4)，det[[4,4],[6,9]]=12=1+11。 |
| determinants/invertibility | 同阶方阵乘积律；逆式须非奇异。A=diag(2,3)逆行列式1/6，与乘积为1一致。 |
| matrices/equations | AXB=C分别左右消去，次序A⁻¹CB⁻¹不可换；代回为C，逆映射保证唯一。 |
| matrices/rank | 实Gram核相同由‖Ax‖²证明；指出复数情形需共轭转置。 |
| matrices/powers | A²=(vᵀu)A后归纳；vᵀu=0时k≥2幂为0，k=1单独解释，未把正整数式用于A⁰。 |
| vectors/span | 从交空间基分别扩充，公共基只数一次；二维相交直线同线时1+1−1=1，异线时1+1−0=2。 |
| vectors/coordinates | Gram正定来自无关性；非正交基v₁=(1,0)、v₂=(1,1)，x=(2,1)给G=[[1,1],[1,2]], b=(2,3)，解c=(1,1)。 |
| systems/classify | 相容解集为特解平移核，仿射维数n−rankA；无解时不写此式。 |
| systems/solutions | 两解系数和1则右端仍b；只有核一维且两解不同才覆盖整条解集。 |
| eigen/spectral | Aᵏv=λᵏv按系数相加；未以该式声称普通矩阵一定可对角化。 |
| eigen/similarity | 正定谱取正根后平方还原；其他正定平方根与A交换，在每个特征空间只能取正根，故唯一。 |
| quadratic/normal-form | 展开两平方差得2xy，变换行列式−2；非单位化替换的系数不冒充正交谱。 |
| quadratic/definiteness | 标量主元a>0才可除；取x=−bᵀy/a核查剩余正定的必要性，配方给充分性。 |
| events/direct-probability | 两个互斥差事件相加，交项扣两次；独立公平事件代入得1/2。 |
| events/conditional-inference | 两个贝叶斯式相除；特列先验及条件似然的非零分母条件，不把零似然比当普通实数。 |
| events/independence-bounds | 四区域非负性给可达界；p=.7,q=.6时交概率位于[.3,.6]，独立值.42合法。 |
| distributions/count-models | 二项相加必须同p且独立；合并n+m个伯努利给分布。 |
| distributions/cdf-density | 左端闭区间必须扣F(a−)，令a=b即单点质量；连续时才可换F(a)。 |
| distributions/functions | 平方的正负两个原像都计入；X在[−1,1]均匀时f(y)=1/(2√y),0<y<1，积分为1。 |
| joint/joint-marginal | 四个CDF矩形增量按容斥，端点为左开右闭；无密度假设。 |
| joint/conditioning | 联合正态残差均值0、协方差0、方差σX²(1−ρ²)；只有联合正态才由零协方差推出独立。 |
| joint/transformations | 独立样本CDF乘积求导；n=2、U(0,1)给最大密度2x与最小密度2(1−x)，均归一。 |
| moments/expectations | 非负变量逐点写为尾指标积分，非负交换成立；允许期望正无穷，不暗含有限性。 |
| moments/variance-dependence | 中心化条件残差的条件均值为0消交叉项；要求有限二阶矩。 |
| limit/convergence | 方差σ²/n代入切比雪夫；σ²=1,ε=.1,δ=.05得n≥2000保证，未宣称最小必要量。 |
| limit/normal-approximation | 整数区间[a,b]扩到[a−.5,b+.5]，用np和np(1−p)标准化；只写近似无误差承诺。 |
| sampling/statistics | 平方和正交分解给自由度(n−1)+1=n且两项独立；n≥2，已知均值与估计中心不混同。 |
| sampling/ratios | 标准正态平方为χ²₁；F倒数同时交换分子分母自由度，不保持原自由度顺序。 |
| estimation/point-estimators | 指数尺度对数似然导数(Σx−nθ)/θ²，先正后负；参数化明确为尺度而非率。 |
| estimation/quality | 展开平方得凸二次式；a=1,b=2时无偏系数1、MSE最优1/2，后者最小MSE为θ²/2。 |
| estimation/confidence-intervals | 方差比在枢轴分母，取倒数翻端点；采用下尾p分位数，组间独立及正态条件写明。 |
| testing/mean-tests-power | 真实均值下标准化拒绝阈值；μ=μ₀功效α，μ增加功效增加，β为其补数。 |
| testing/variance-tests | H₀下样本方差比除r₀，两个独立卡方按各自自由度归一化给F；未拒绝不写成证明。 |
