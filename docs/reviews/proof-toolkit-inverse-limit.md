# 证明工具库与反函数极限独立复核

日期：2026-09-08；非原作者逐条审查条件、步骤、公式和例题。四张均通过，标 reviewed；无需数学修正。

| 方法 | 实际核验 |
| --- | --- |
| proof-contradiction | 按经典逻辑，假设最小正实数 a 存在，则 a/2 严格位于 0 与 a 之间，满足同一定义域且直接违反最小性。否定量词与逆命题的区分正确。 |
| proof-counterexample | 绝对值函数全实轴连续；零点差商左侧 −1、右侧 1，导数不存在。反例满足全部前提，否定的只是原全称命题。 |
| proof-induction | 基例 1=1²；从 k² 加下一奇数 2k+1 正好是 (k+1)²。整数起点、任意合法递推步及步长 2 时的两类起点要求正确。 |
| hm-inverse-limit | 连续严格单调函数在有限闭区间上为到像区间的同胚；像为闭区间，极限仍在反函数定义域。sin 在 [0,1] 的导数 cos x>0，arcsin 连续，故指定极限为 1/3；交替符号的平方反例明确表明一般连续映射不能反推收敛。 |
