# 逐级交付路线图

基线：`MVP.md`。阶段只有在验收证据成立时才能标记完成；页面有入口、JSON 有记录或构建成功均不等于内容完成。当前实施状态由 `STATUS.md` 记录，本文件固定目标与验收。

## 完整目标与边界

- 体系：首个正式体系为「考研数学一」，包含高等数学、线性代数、概率论与数理统计；第二个小型体系用于验证隔离与切换。
- 课纲版本：以 **2026 年全国硕士研究生招生考试数学考试大纲**的数学一部分为首个核验目标。未获取并逐项核验正版大纲前，标为「2026 课纲映射草案」，不得写“官方完整覆盖”。后续版本独立建立差异清单。
- “全部方法”：指冻结的课纲要求清单中，每项可考计算、证明、判别或应用任务都有至少一个可执行方法及适用条件；同时覆盖编审列出的常见替代方法。不是数学技巧穷尽，也不能用少量宽泛章节卡冒充完整方法。
- 每个方法最少包含：稳定 ID、所属体系/章节、映射课纲条目、适用/不适用条件、具体步骤、公式、易错点、一个原创例题及答案/推导、相关方法、编审状态。仅标题/通用模板不计覆盖。
- 首个完整真题范围：**2009—2026 年数学一（301）正式初试卷，共 18 个招生年份**；按招生年份记年（通常上一自然年考试），排除模拟卷、回忆补题及数学二/三。2008 年及以前作为后续扩展，不能暗示已经覆盖。
- 真题完成：范围内每卷来源核验、全部题号逐题建档、可查看原题的合法公开来源或获授权本地正文、原创解题摘要、方法关联及独立核验均完成。只有年份导航或整卷链接称为“试卷目录”，不称“完整真题库”。

## P0：可执行合同与工程骨架

产出：MVP、架构、路线图、实现速查；独立 Git 仓库与公开远端；结构化内容 schema、构建、校验和 CI。

验收：代码文件 ≤250 行；无悬空 ID、重复 ID、跨体系误引用；空库可正常呈现；新体系通过复制模板和 CLI 校验即可添加，无需浏览器编辑。文档给出唯一实现入口、模块职责、常用命令、内容状态，避免逐函数记录。

## P1：垂直 MVP

产出：全图平移/缩放、节点拖动、适配全图、章节聚焦、搜索定位、方法详情和移动端目录；至少三个学科各有可读方法，并有第二体系演示。

验收：从搜索或图节点打开同一方法；URL 可复现选择；键盘可从目录完成检索；定位动画遵循 reduced-motion；窄屏详情可关闭，图操作不吞掉内容滚动。新增 JSON 方法不改前端源码。真实真题若未收录显示“尚未收录”，不显示零次考试。

## P2：课纲要求清单冻结

产出：按课纲逐项建立稳定 requirement ID，记录版本、来源和人工复述；每项列出目标方法 ID 与缺口。覆盖高数的极限连续、一元微积分、空间几何、多元微积分、级数、微分方程；线代的行列式、矩阵、向量、方程组、特征值/二次型；概率统计的概率、随机变量/联合分布、数字特征、极限定理、统计量和参数估计等，最终边界以正版课纲核验为准。

验收：章节、要求、方法三个层次分开；有课纲来源证据与复核记录；不存在仅将章节名计作单一要求的覆盖率。草案覆盖和核验覆盖分别统计。若来源不足，完成草案并继续 P3，不伪造核验状态。

## P3：方法内容逐章完成

顺序：极限/连续 → 导数与应用 → 一元积分 → 多元微积分/几何 → 级数/微分方程 → 线代 → 概率统计。

每批产出：一个章节的要求映射、实际可用方法、原创算例、相关方法边。方法粒度以可独立选择执行为准；例如换元、分部积分、反常积分判别分别建卡。

验收：每个卡片步骤具体、条件完整、算例计算可复核；每项要求均有通过复核的方法。独立内容复核检查遗漏与数学错误，确定性 schema 校验不能替代数学复核。覆盖报告列出分母、已写/已复核数和缺口 ID。全纲完整状态仅在要求无缺口且方法全部复核后授予。

## P4：真题来源与逐题索引

顺序：2025 → 2024 → 2023 → 2022 → 2021 → 2026 → 2020 向前至 2009；先验证一卷端到端，再批量拓展。

每卷记录：招生年份、301、来源 URL/站点/访问日、是否原始发布方、真实性证据、正文提供方式及权限依据、题号清单与完整性状态。每题稳定键为年份+301+题号，子问作为子条目，避免重复次数。按原卷核定题数，不对跨年份卷式套同一题数。

验收：每题可定位到来源页/题号；来源失效可明确提示；记忆版与核验版区分。试卷目录可以先交付，未完成题目显示待录入；本地全文缺授权不阻塞来源链接与原创摘要，不能把外链模式称为本地全文题库。

## P5：方法关联、审计频次与真题检索

产出：每题的方法关联带原创判断理由、主/辅方法、复核状态与来源定位；按方法/年份/学科筛题，逐题查看来源和摘要。

验收：默认仅对已核验关联计数。题次数按唯一题键去重；试卷次数按年份+卷种去重；同题多个子问不重复增加题次数。展示“已核验 X 题 / 已收录 Y 题，范围 A—B，完整试卷 N/18”；缺失卷不能进入完整覆盖分母。方法 0 次仅可表述为“当前已核验数据中 0 次”，无关联记录则显示“尚无已核验关联”。测试包括同题多标签、子问、待审关联和缺失年份。

## P6：交付与总体验收

产出：可访问的只读前端、所有目标要求的方法内容、18 卷完整逐题库、审计报告、编辑指南、公开仓库最新提交。

验收：P0—P5 全部证据通过；移动端/桌面图谱检索链路实测；完整数据下平移/缩放和搜索可用，按测量结果采用折叠或分层渲染；空态/错误态/无障碍路径通过；命令校验、测试、构建及 CI 成功；README 清晰记录版本、真题范围、部署地址和剩余限制。未完成来源授权或独立复核时仅发布带明确缺口的阶段版本，不标记总目标完成。

## 来源与核验策略

优先教育部教育考试院/官方出版物，其次高校公开资料，再以教育门户或培训机构做交叉对照。公开可访问不代表允许仓库再分发；来源真实性与复制许可分别记录，未知许可采用外链和原创摘要，不下载后直接提交扫描件或第三方解析。出现来源冲突保留冲突记录，暂不计入已核验频次。

本轮确认的发现入口（2026-09-08；仅发现入口，不代表所有年份/题目或授权已核验）：

- [中国教育在线数学大纲目录](https://kaoyan.eol.cn/kao_shi_da_gang/shuxue/index.shtml)：辅助发现历史大纲，非官方原始出版物。
- [中国教育在线历年数学真题目录](https://kaoyan.eol.cn/shiti/shuxue/)：可发现 2024/2025 等数学一页面；需逐卷核验。

## 持续推进与提交节奏

每个阶段/章节/试卷形成一个可复核提交：先读实现速查 → 处理最高优先未完成项 → 运行对应检查 → 更新 STATUS 和速查中的变化 → commit → push。不得以写路线图替代实施，不把未核验内容通过改状态“完成”。

来源或授权受阻时记录精确缺口并继续方法编写、其他试卷索引、前端与测试；待全部独立任务完成才汇报外部阻塞。持续执行中保留失败证据；改变范围或验收标准要记录理由，不能为了完成而收缩到演示内容。仅修复已发现的问题，不增加没有明确用途的框架或平行实现。
