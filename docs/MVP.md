# MVP 产品设计

面向考研数学一复习者的只读方法图谱。界面极简，全屏思维导图占绝大部分面积，搜索和画布控件轻量悬浮，目录与方法详情按需展开。全图拖拽缩放、节点拖动、章节聚焦、搜索定位、目录替代操作；选择方法显示条件、步骤、公式、易错点、自编例题、相关方法及真题证据。动画表达定位与展开，遵守 reduced-motion。

内容目标覆盖高数、线代、概率统计；以版本化课纲考点→方法映射验收，不能宣称数学方法穷尽。结构化文本按体系/方法/题目拆分，稳定 ID、引用校验、CLI 校验，AI 无需 GUI 即可修改。支持多个独立体系，前端只读。

真题按年份/卷种/题号唯一标识，记录来源、核验状态和方法关联。频次由已核验关联计算，区分题次数和试卷次数，显式展示数据覆盖；没有记录表示尚未收录，不能等同于从未考查。原题版权不明时提供原始来源查看与原创解题摘要，不复制整套受保护解析。

MVP 首先打通图谱→方法→来源真题的检索链路，再扩展到完整课纲方法覆盖及历年试卷目录和逐题索引。公开仓库不包含凭据或私人文件。

工程要求：实现前阅读架构速查和路线图；代码文件硬限制 250 行，按职责拆分，禁止另起重复实现；每个里程碑运行校验/测试/构建并提交 push。实现状态和未验证项准确记录。
